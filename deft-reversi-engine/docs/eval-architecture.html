deft_reversi_engine の eval 構造

`eval` は盤面を現在手番側から見た disc score に変換する内部コンポーネントです。 公開入口は `Evaluator` enum で、実装として通常の pattern 評価と NNUE 評価を切り替えます。

入口

Evaluator が pattern / NNUE を包みます。

状態

EvalState が探索中の feature 状態を持ちます。

評価値

返り値は現在手番側から見た -64..64 の disc score です。

保存形式

EngineFile v3 が評価重みと MPC 設定を保存します。

全体の流れ

Evaluator と EvalState

`Evaluator` は評価重みを持つ immutable な型です。探索側は `Arc<Evaluator>` として共有します。 `EvalState` は局面ごとの feature 状態で、評価器の種類と一致している必要があります。

型 役割 中身
Evaluator::Pattern 通常の pattern 評価を実行する。 PatternEvaluator
Evaluator::Nnue NNUE 評価を実行する。 NnueEvaluator
EvalState::Pattern pattern code を保持する。 FeatureIndexes
EvalState::Nnue NNUE の active feature id を保持する。 NnueState

評価値の共通ルール

pattern 評価も NNUE も、最後は raw score を SCORE_SCALE = 128 で丸めて disc score にします。 返り値は常に現在手番側から見た値で、最終的に -64..64 に clamp されます。

raw score -> round(raw / SCORE_SCALE) -> clamp(-64, 64)

PatternEvaluator

通常評価は、既存の n-tuple pattern code と mobility weight を phase 別に足し合わせる構造です。 phase は Board::move_count() から求め、最大 N_PHASES - 1 に丸めます。

FeatureIndexes

盤面の各マスを 0: empty、1: opponent、2: player として base-3 encode します。 現在は 11 patterns x 4 rotations = 44 個の pattern code を持ちます。

重み

file 上は pattern ごとに分かれた重みを持ち、読み込み後は phase 内で flat table に変換します。 評価時は pattern ごとの offset を進めながら参照します。

phase = min(board.move_count(), N_PHASES - 1)
score = sum(pattern_weight[pattern_offset + pattern_code]) + mobility_weight[mobility_idx] + bias
mobility_idx = N_MOBILITY_BASE + player_moves - opponent_moves

NnueEvaluator

NNUE は pattern 評価とは別の評価器です。入力 feature は現状維持で、 n-tuple pattern、手番側/相手側の石、合法手数ペアを active feature id に変換します。

NNUE input 内容 active 数
n-tuple pattern FeatureIndexes の pattern code を NNUE の feature id 空間に配置する。 常に 44
stones 手番側の石 64 features、相手側の石 64 features。 盤上の石数
mobility pair player_moves * 34 + opponent_moves の 1 feature。 常に 1
合法手入力は合法手のマスそのものではなく、手番側と相手側の合法手数ペアです。 現在の default NNUE 重みは全て 0 なので、未学習状態では評価値 0 を返します。

EngineFile v3

評価重みは EngineFile の evaluator に保存されます。 EvaluatorData は tagged enum で、kind: pattern または kind: nnue を持ちます。

Pattern data

PatternEvaluatorData は phases: Vec<PhaseData> を持ちます。 各 phase は pattern weights、mobility weights、bias を保存します。

NNUE data

NnueEvaluatorData は input weights、input bias、dense layers、output weights を保存します。 shape は読み込み時に固定値と照合されます。

使い方

let engine_file = EngineFile::read_file("data/eval/eval.bin")?;
let (_metadata, evaluator, _mpc) = engine_file.into_parts()?;

let state = evaluator.state_from_board(&board);
let score = evaluator.evaluate(&board, &state);

// 単発評価や test 用
let score = evaluator.evaluate_board_slow(&board);
