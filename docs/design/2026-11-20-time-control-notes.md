## 4. 段階1の途中結果（1-1〜1-4）

データは、probe（置換表を空にして1スレッド、6秒まで）と参照探索の2,639局面（264局）。反復の時間が10ms以上の行だけを使う。偶数番と奇数番の局で交差検証した。

- 誤差は ln(実際の比 / 予測した比) の RMSE。
- 「打ち切り」は、次の反復が6秒以内に終わらなかった行。Tobit（打ち切りを下限として扱う回帰）でも確かめ、結論は変わらなかった。

```sh
python3 tools/time-control/features.py \
  docs/benchmarks/2026-11-20-time-allocation-loss-table/{games,probe}.txt \
  --offset 1000 docs/benchmarks/2026-11-20-time-stopping-oracle/{games,probe}.txt > table.tsv
python3 tools/time-control/cost_fit.py table.tsv
```

盤面の再現は、全局面で probe の手が合法手になることで確かめた。

| 遷移 | 行数（打ち切り） | 今の式 | 定数 | 効いた特徴量（交差検証の RMSE） | 効かなかった特徴量 |
|---|---|---|---|---|---|
| 中盤→中盤 | 12,265（8%） | 0.94（×2.56）、平均で多く見積もる（−0.21） | 0.66 | 前の比（係数 −0.35）→ 0.61、空き数・深さ → 0.59、直前の時間 → 0.58 | 合法手の数、偶奇、隅、評価値 |
| ENTRY | 1,194（15%） | 0.65 | 0.66 | 空き数 → 0.63、深さ・偶奇 → 0.62、**直前の時間（係数 −0.31）→ 0.53**、前の比 → 0.51 | 盤面の特徴量（0.50） |
| EXACT | 986（19%） | 0.64 | 0.70 | 空き数 → 0.63、**直前の時間（係数 −0.49）→ 0.53**、**盤面（手番側の合法手の数 +0.11/手、隅）→ 0.45** | 直前のステージ |
| ステージ間 | 3,047（8%） | 0.53、平均で多く見積もる（1.25 は大きすぎ、−0.18） | 0.50 | 直前の時間 → 0.49 | 空き数、ステージ、盤面 |

読み取れること：

- **中盤→中盤の今の式は、定数より悪い**（RMSE 0.94 と 0.66）。直前の比をそのまま次に使う（傾き +1）が、実際は逆戻りする（傾き −0.35）。多く見積もるので、早めに止まりすぎる。監査の「中盤の使用時間 / soft の中央値0.67」と合う。
- ENTRY と EXACT は、**直前の反復の時間が長いほど倍率が小さい**（時間はおおよそ直前の時間の0.5〜0.7乗で増える）。今の式は直前の時間に比例すると仮定している。
- EXACT だけは、盤面の特徴量（合法手の数）が効く。
- 盤面の特徴量は、中盤→中盤と ENTRY ではほとんど効かない。

注意：これは置換表が空のときのデータ。対局中（置換表が温まっている、`reuse_pv`）で同じ傾向かは、GTP ログ（反復の時刻はあるが、盤面・評価値はない）で確かめる必要がある。ノード数は probe に入っていないので、まだ調べていない。

## 5. 段階1の結論（1-7）

まとめは `docs/benchmarks/2026-11-20-time-prediction-features/README.md`。4章の probe の結果に加えて、次のことが分かった。

- 対局ログでも、中盤→中盤の今の式は定数より外れる（0.92 と 0.70）。前の比の係数は −0.37 で、probe と同じ。4スレッドでも同じ。
- 対局中の EXACT は、今の式が約2〜2.5倍多く見積もる（置換表が温まっているため）。ENTRY も4スレッドで多く見積もる。
- 予約：実際は見積もりの0.2〜0.4倍（4スレッドで約0.1倍）。前の自分の手番の使用時間がいちばん効く。
- 価値：最善手が変わったか以外は、ほぼ効かない（R² 約1%）。

これを受けて、2-4 のログに入れるもの：
- 反復ごと：kind、next、elapsed、nodes、score、best_move、pv
- 盤面：空き数、両者の合法手の数、偶奇の領域の数
- 文脈：前の手番の到達ステージ・使用時間・pv[1] と実際の手の一致
- 時計：remaining、cap、soft、hard、プロトコル、スレッド数、止めた理由
- 予測：Forecast が予測した次の反復の時間

エンジン内部の値（上位2手の差）は、価値の予測の残りの候補だが、探索本体への計測の追加になるので、2-4 では入れない。
