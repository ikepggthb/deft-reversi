## 基本の流れ

校正済みモデルで小さい予算から生成する。範囲と損失条件を調整して有望な分岐を追加し、必要に応じてレベルを上げる。子を育てた結果は自動で親へ戻る。`leaves`で既存局面の未登録候補を再計算し、`inspect`で品質を確認する。

`.dbook-work`は生成・更新の元データと再開状態を保存するファイル。`.dbook`は対局用の読み取りデータを出力する任意のファイルで、生成再開には使わない。対局中に勝手に生成・保存しない。使えるbookの手がなければ通常探索へ戻す。

既定の対局条件は中盤12手・95%以上、選択的終盤85%以上。これはAPIの既定値であり、棋力を最適化した推奨値ではない。完全読み切り、選択的終盤、中盤推定を区別して使う。短時間の生成や参照速度だけで強いbookが完成したとは扱わない。
