# エンジンリライト: 採用方針と進捗

## 確定した方針

- 目的は保守性・設計の改善と、実測で確認できる高速化。
- 参照元は `../deft-reversi-feature`（f4192a0）。参照先のRustソースは変更しない。
- 初回はネイティブ向けエンジンと検証用ツールのみ。
- 既存11パターンの特徴量・学習済み重みを活用。APIと内部形式の互換性には縛られない。
- YBWC並列探索を初回の対象に含める。
- NNUE、Web/WASM、対局CLI、学習処理、対局履歴の移行は後続。

## リソース制約の解除

ユーザーからGPUベンチマーク終了の連絡を受け、ビルド・テスト・モデル変換・性能測定を再開した。GPUは使用していない。

## 実装した範囲

1. 非公開ビットボード、Square/Action、検証付き着手、終局スコア。
2. パターンモデル、固定スキーマの格納、既存モデル変換、差分特徴量。
3. PVS/NWS、反復深化、終盤の浅い予備探索、アスピレーション窓。
4. 共有TT、満杯のラインと接触も扱う安定石カット、4空き以下の専用処理、較正を明示するMPC。
5. 常駐ワーカー、YBWC、祖先への直接ハンドオフ、局所/全体停止、仕事の回収。
6. 公開要求・結果・統計・エラー、検証用solve、任意実行の旧版比較ツール。
7. 盤面・評価・モデル・探索・並列性の検証ケース。

詳細なAPIと実行手順は [エンジンREADME](../deft-reversi-engine/README.md) を参照。

## 設計上の契約

- 手番相対の盤面と評価値。パスでは探索深さを減らさない。
- 完全読みはMPCを禁止。選択的終盤は別の方式として表示する。
- 中断時は最後の完了反復を返し、要求された完全読みが終わったかを区別する。
- 特徴量・PV・統計は探索経路/ワーカーに所有させ、モデルとTTを共有する。
- TTは盤面・深さ・探索方式・選択性を照合。中断ノードを保存しない。
- 祖先への仕事配布は子孫からのみ。分割点と要求は配布済みの仕事を回収してから終了する。
- 1スレッド時はワーカープールを作らない。
- 環境変数・標準出力・UI・ファイル配置を探索本体から分離する。
