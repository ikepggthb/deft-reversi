# MPC を1,000局面で校正したモデルの速さ（2026-11-07）

PEN のモデル（`full-pen.dpr2`）の MPC を、空きマスごとに250局面で校正したもの（`mpc-pen/model.dpr2`）と、1,000局面で校正したもの（`mpc-pen-1000/model.dpr2`、sha256 `aa2d7cd9…1f05a8`）の速さを比べた。

## 結果

3回ずつ、順番を入れ替えながら測った。ノード数は3回とも同じだった。

| | レベル21 | レベル24 と同じ手 | レベル18 | FFO 40〜59 |
|---|---|---|---|---|
| 250局面 | 65.98〜67.33 s（929M） | 82.7%（\|d\| 1.65） | 22.06〜22.16 s（313M） | 210.85〜211.57 s（12.22G） |
| 1,000局面 | 98.38〜98.61 s（1,383M） | 81.3%（\|d\| 1.67） | 21.85〜21.93 s（310M） | 210.45〜210.93 s（12.20G） |
| レベル21、64番を除く | 250：56.70〜58.04 s（801M）／1,000：57.33〜57.45 s（810M） | | | |

- FFO 40〜59 の石差は、どちらも i3 で測った前回（[../2026-11-06-pen-tuning](../2026-11-06-pen-tuning/README.md) の `final`）とすべて一致した。
- **レベル21 の差（+453M ノード）は、ほぼすべて中盤150局面の64番1つから来ている**（250局面：129M・9.3 s、1,000局面：574M・41.2 s）。64番を除くと、差は +1.1% のノード、時間はほぼ同じ。
- 64番をレベル20 と22 で読むと、2つのモデルの差はない。

| 64番 | レベル20 | レベル21 | レベル22 |
|---|---|---|---|
| 250局面 | 171M・11.9 s | **129M・9.3 s** | 524M・37.3 s |
| 1,000局面 | 177M・12.4 s | **574M・41.2 s** | 501M・35.7 s |

  250局面はレベル21 だけ極端に速く、1,000局面はレベル21 がレベル22 より重い。どちらもその深さでの偶然（ProbCut で刈れるか、読み直しになるか）で、校正の良し悪しによる差ではないと考える（推測）。

## 測り方

- この PC（Core Ultra 7 265K）で測った。前回の値（i3-14100）とは時間を比べない。
- `examples/solve`（`0f11ef5`、`-Ctarget-cpu=native`）を1スレッド、CPU 2（P コア）、TT 256 MiB で、1つずつ順に動かした（[bench.sh](bench.sh)、順番は [queue.sh](queue.sh)）。
- 局面と、手の質の比べ方は前回と同じ（[mid150.obf](../2026-11-03-midgame-speed/mid150.obf)、[ffo40-59.obf](../2026-11-06-pen-tuning/ffo40-59.obf)、[ref-l24.tsv](../2026-11-06-pen-tuning/results/ref-l24.tsv)）。
- 結果は [bench.log](bench.log) と [results/](results) にある。64番は [p64.obf](p64.obf)。

## 校正そのものの比較

- 250局面の10,250局面は、1,000局面にすべて同じ値で入っていた。
- 判定の幅（p=0.99）は、中盤で平均 −0.6%（最大1.1%）、完全読みで平均 +0.1%（最大1.2%）しか変わらない。
- 1,000局面にだけある30,750局面で、250局面の校正のはみ出し率は p=0.99 で 0.96%（中盤）、1.15%（完全読み）だった。
