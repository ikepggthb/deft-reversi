# パターン評価の学習器（v2）の初回学習

`deft-reversi-train` で、Egaroucid 由来の `.rd` データセット（石数12〜63、train 約13.7億局面）を全件・4エポック学習した。

- コマンド：`deft-reversi-train train --data egaroucid_rd_data_set --work full --out full.dpr2 --epochs 4 -t 16`
- 設定は既定値：lr 0.05、L2 1e-4、Huber 4石、shrink 32、seed 1
- 実行環境：Core Ultra 7 265K、16スレッド。所要637秒
- 段階・エポックごとの記録は [metrics.jsonl](metrics.jsonl)

## test 分割の平均絶対誤差（石）

エンジンの `PatternModel::evaluate`（整数に丸め、±64に制限した値）と最終石差の差。全文は [eval-test.txt](eval-test.txt)。

| 石数 | 局面数 | 今のモデル（deft-eval-main.dpr2） | 以前の学習器（pattern-full-e8、8エポック） | 新しい学習器（4エポック） |
|---:|---:|---:|---:|---:|
| 12 | 10,164 | 8.915 | 6.325 | 6.365 |
| 20 | 90,378 | 6.567 | 6.381 | 6.412 |
| 28 | 170,506 | 6.218 | 6.188 | 6.251 |
| 36 | 250,465 | 5.925 | 5.579 | 5.654 |
| 40 | 290,284 | 5.489 | 5.570 | 5.098 |
| 48 | 369,764 | 5.408 | 5.413 | 4.900 |
| 56 | 448,750 | 5.074 | 5.089 | 4.632 |
| 60 | 486,870 | 3.894 | 3.924 | 3.617 |
| 63 | 501,619 | 0.617 | 0.001 | 0.002 |
| 石数ごとの平均 | 13,746,986 | 5.743 | 5.514 | 5.334 |

石数40以上では、新しい学習器が 0.3〜0.5 石小さい。石数36以下では、8エポック学習した以前のモデルより 0.03〜0.08 石大きい。valid の誤差は4エポック目でもまだ下がっていた（例：石数40で 5.454 → 5.256 → 5.169 → 5.118）。

## レビュー後の再学習

Codex のレビューを受けて次を直し、同じ設定で学習し直した。表の値は再学習後のもの。

- 対称な配置で複数の向きが同じ重みを指すとき、勾配を足して1回だけ更新する（以前は向きの数だけ別々に AdaGrad 更新していた）
- チェックポイントに train ファイルの識別情報を記録し、違うデータでの再開を拒む
- 再開時に終えたエポックのシャッフルをやり直し、中断しなかった場合と同じ順序にする
- 局面の無い段階はチェックポイントを作らない。学習率などの数値を検査する

修正前のモデルとの差は、どの石数でも 0.002 石以内だった（[eval-test.txt](eval-test.txt) の model 3 と model 4）。

探索の強さ（対局・FFO）はまだ比べていない。
