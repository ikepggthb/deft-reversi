# PEN 評価関数のWASM移植（2026-11-07）

移植元は `feature/engine-v2` の `04c2ecb`。PEN評価・DPR2 v3と校正済みProbCut・単一スレッド探索の改善を、独立したWASMエンジンへ移した。以前のWASM用合法手生成と終盤処理も維持した。

PENの隠れ層は、符号付き8ビットの重みと0〜127の入力を16ビットへ拡張して乗算し、隣接する積を32ビットに加算するWASM SIMDで計算する。入力が127以下なので符号付き変換で値は変化せず、積と途中の和もあふれない。ランダムな入力・重みについてスカラー版と完全一致を確認した。新しい正式モデル（SHA-256 `aa2d7cd9e42e8f8f7df4f547124683fc86d85cb83b83b332637f07dc1d1f05a8`）では、移植元と移植先で10万盤面の評価値、20盤面のレベル8探索の最善手と評価値が一致した。

## FFO 40〜49の合計時間

同じモデル・同じ探索コードで、PEN隠れ層のみスカラー／SIMDに切り替えた。Chrome 154のWeb Worker、AMD EPYC 9V74、CPU 0固定、Rust 1.99.1 release `+simd128`、wasm-bindgen 0.2.129。今回は `wasm-opt` は適用していない。TTは32 MiB、各局面前に初期化、完全読み、時間制限なし。旧→新→新→旧の順に測定した。

| 実行の組 | PENスカラー：10問合計 | PEN SIMD：10問合計 |
|---|---:|---:|
| 前半 | 28.733秒 | 23.405秒 |
| 後半 | 28.200秒 | 23.219秒 |

各問の最善手・評価値・ノード数は全回一致し、合計383,322,547ノード。時間はモデル読み込みとTT初期化を含まない。端末や負荷によって差は変わる。[各問の生データ](results/chrome.jsonl)。Node.js v24.19.0でもスカラー28.092秒→SIMD 23.308秒→SIMD 23.142秒→スカラー28.367秒だった（[生データ](results/)）。

別途、通常のベンチマーク画面から10問を完全読みし、23.10秒で全問正解を確認した。この1回の計測はCPU固定ではない。新評価・探索順序によって探索量が変わるため、従来モデルとの時間差をSIMDだけの効果とは扱わない。

Web配布時はGitHub Releaseから179,148,252バイトのモデルを取得し、SHA-256を照合してgzip圧縮する。配布ファイルは約69 MiBで、ブラウザーでは展開されたモデル・WASMメモリ・置換表などの追加メモリが必要になる。
