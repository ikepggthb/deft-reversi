# Edax・Egaroucid との対局（2026-11-03〜04）

Deft の強さを、Edax 4.5.5・Egaroucid 7.8.1 との対局で、同じレベル同士で比べた。

- **Deft**：エンジンは 485b667 に [中盤探索の高速化](../2026-11-03-midgame-speed/README.md) を入れた作業ツリー。モデルは `mpc-formula/model.dpr2`。
- **Edax 4.5.5・Egaroucid 7.8.1**：配布されているバイナリ。
- **序盤**：XOT の一覧（[xot-openingslarge.txt](xot-openingslarge.txt)、10,784局面、8手ずつ）から、乱数（種1）で選んだ。1つの序盤を、先手・後手を入れ替えて2局打つ。
- **探索の条件**：どのエンジンも1スレッドで、先読みはしない。ハッシュは、Deft が 64 MiB、Edax と Egaroucid が 2^21。
- **進め方**：1局ずつ順に打った。両エンジンを同じ物理コアに固定した（探索は交互で、ぶつからない）。
- **思考時間**：各 `genmove` の応答にかかった実時間を、1局ごとに記録した。

### 1つの探索の中の進め方

**Deft**
- **中盤**：2手ずつ深くする反復深化。どの反復も、レベルの確率（レベル11・12・21 では 85%）で読む。
- **完全読み・選択的な終盤探索**：まず空き数 − 8（最大24）まで、85% の中盤探索で準備する。そのあと、85% の終盤探索から目標の確率まで上げる。
  - 空き27未満：85% のあと、すぐ目標の確率へ。
  - 空き27〜29：85%・95% のあと、目標へ。
  - 空き30以上：85%・95%・98%・99% のあと、目標へ。

**Edax**
- 空き30の完全読みでは、浅い探索（73%）のあと、73・87・95・98・99・100% と上げていった（`-vv` の出力で確認。[2026-11-03-endgame-large-empties](../2026-11-03-endgame-large-empties/README.md)）。

**Egaroucid**
- レベルの表のほかは、ソースを確かめていない。

### 違いのまとめ

- **Deft のレベルの表は、Edax の表を移したもの**で、空き数の区切り方が同じである。ただし MPC の確率の番号を自分の目盛りに読み替えたため、**中盤探索の選択性が違う**。Edax の 73% にあたる所が、Deft では 85% になっている。Deft の中盤探索は、同じレベルでも刈りが少なく、手間がかかる。
- **Egaroucid は、終盤の確率の段が細かい。** レベル11・12 では、完全読みに移る空き数も Deft・Edax より3つ多い（98% で空き25から）。
- レベル1・5 は、3つのエンジンで中身が同じである。

## 対局の仕組み

- [match.py](match.py)：GTP で両エンジンを動かして対局させる。
  - `levelN`：両方がレベル N
  - `levelD:E`：Deft がレベル D、相手がレベル E
  - `timeS`、`timeS:D`：持ち時間（1局ずつに限る）
  - `XOT=FILE`：XOT の一覧から序盤を選ぶ
- [tools/](tools)：Deft の GTP プログラム `deft-gtp`（エンジンのライブラリを使う）。
  - `--level N`：レベルを指定して打つ。
  - `--game-ms MS`：持ち時間を指定して打つ。空き20以下はすぐ読み切れるので、残り時間を、空き21以上の自分の手に配る。

### 持ち時間での比較を本題から外した理由

持ち時間でも比べたが、条件をそろえるのが難しかったので、本題はレベル指定にした。

- **Egaroucid**：GTP の `genmove` は `-time` を見ずに、レベルで探索する（`gtp_command.hpp` の `gtp_genmove`）。
- **Edax**：`-t`（1対局の持ち時間）を1秒未満にしても、1局あたり約1.1〜1.2秒より短くならない。`-move-time` を1秒未満にすると、既定の時間で打つ（約3.9秒）。GTP の `time_settings` を送ると、探索が止まらなくなった。
- **Deft**：最初の時間の配分では、持ち時間の約7割しか使っていなかった（空き20未満に割り当てた時間が、完全読みがすぐ終わるので余っていた）。配分を直して、95〜98% を使うようにした。
- **同じ思考時間（約1.15秒/局）での Edax との対局**：Deft は −108・−127 Elo だった。Deft は毎手、打ち切られた反復に時間の4〜5割を使っていて、その分の探索が無駄になっている。新しい反復を始めない時間制限を試したが、強くならなかったので入れていない。
- これらの結果は、[results/](results) の `xot-edax-time*` と `edax-time1-deft1.6.tsv`、`egaroucid11-deft12.tsv`、`xot-egaroucid10-deft12.tsv` にある。
