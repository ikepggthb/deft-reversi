# 60秒対局を見据えた時間管理の変更（`reuse_pv`＋不安定度減衰、2026-11-20）

第1段階（`525a908`）を基準に、1局 60 秒の高精度対局を中心に複数案を調整用開局で比較し、最良だった `warm` 案を独立評価用開局（計 256 局）で検証した。

## 変更内容

1. **置換表からの反復スキップ（`reuse_pv()`）と安全なフォールバック**
   - `deft-reversi-cli/src/game_clock.rs`: `SearchRequest::timed_levels(60, self.hard).reuse_pv().skip_pv_recovery()` を使用。
   - `deft-reversi-engine/src/search.rs`: `warm_start` で初期反復をスキップした直後の未キャッシュ反復で時間切れになった場合でも、最小ビット合法手ではなく TT 上の証明済み最善手を返すようフォールバックを修正（公開 API 変更なし）。
   - 固定レベル 18・204 手番の再生比較で、ノード数が 143.16M → 128.31M（約 10.4% 削減）、時間が 81.30s → 70.94s（約 12.8% 短縮）。
2. **不安定局面の確認延長と減衰**
   - `deft-reversi-cli/src/game_clock.rs`: 最善手が変わったときに `instability = 1.0`（`soft × 2.0`、`hard` 上限内）へ延長し、確認反復ごとに `0.5` 倍へ減衰させる。

## 独立評価結果（`warm` vs `525a908`、計 256 局）

調整用開局と盤面対称性を含め非重複の XOT 8手開局（ID `2200..2231`, `3000..3031`）で先後入替。詳細数値は [summary.tsv](summary.tsv) を参照。全条件で時間超過は新旧ともに 0 件。

**読み方（2026-11-20 追記）**：4条件とも95%信頼区間が0をまたいでおり、どれも統計的に有意な改善ではない。言えるのは「悪化は見られない」までである。調整用開局での候補比較（上の表）も 16〜32局ずつで、どの案の差も誤差の範囲にある。多くの案を同じ調整用開局で比べて最良を選んでいるので、`warm` が良く見えるのは偶然の可能性もある（独立評価で悪化がないことは確かめている）。
