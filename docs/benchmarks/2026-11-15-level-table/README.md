## 1. 前段（2026-11-09）

[2026-11-09-endgame-mpc](../2026-11-09-endgame-mpc/README.md) で、空き14〜24の各200局面について、終盤探索の各選択率と中盤83%の各深さの精度・時間を測った。[2026-11-09-level-endgame](../2026-11-09-level-endgame/README.md) で、それをもとに「空き数−レベル」で区切りを決める規則を作り、旧表と対局した。要点：

- 旧表は低いレベルほど終盤が重い。終盤を中盤の数倍の時間に抑え、浮いた時間で中盤を1〜3段深くすると、同じ時間の旧表より約70〜90 Elo 上だった（ただしこの対局では案の側だけ序盤補正がなかった。2026-11-09-level-endgame に追記した）。
- 68%・77%は使わなくてもほぼ変わらない。

この対局のうち旧表のレベルを1つ上下させた組から、1段上げる代価（同じ側の1局あたりの時間の増分 ÷ 石差の増分）を出した。L16：(1.310−1.056 s)÷(0.71+0.55石)＝約0.2 s/石、L20：(6.287−4.994 s)÷(0.54+0.38石)＝約1.4 s/石。これを §2 の「石の値段」に使った。

## 2. 局面ごとの損失の測定（11-10〜11）

対局は1局の石差のばらつき（標準偏差 約3石）が大きく、0.1石の差を見るには約900局要る。そこで、ゲームに出る局面で各探索方式が選ぶ手の損失と時間を直接測り、レベルごとに「時間＋値段×損失」が最小の表を求めた。

### 方法

- 局面：Deft 同士の自己対戦（XOT開局、レベル26・28・30 各50局）に出た局面。同じ局面は1回だけ数える。対局に使った区切りの表はフォルダに記録が残っていないが、局面の標本としてだけ使う。
- 探索：その局面の手番側が対局中と同じように探索する。2手前・4手前の自分の手番で中盤探索を行い（置換表を引き継ぐ。中盤の方式はそのレベル、終盤の方式はレベル16の中盤）、その局面で比べる方式を1回探索する。1スレッド、置換表64 MiB、ジョブごとに新しい表。時間はその局面の探索だけ。i3-14100。測定ツールは当時の `tools/bench/level_cost.py` と `examples/level_cost.rs`（今は削除）。
- 中盤の選択率は83%（当時は85%段の倍率を1.2691755に置き換えて実現。今の83%段と同じ値。§7）。
- 損失：比べた方式が選んだ手を、より正確な探索で評価し、その中の最善との差（石）。空き28以下は完全読み、29〜32は99%、33〜34は98%、35〜36は95%、37以上はレベル36の中盤探索。損失は「比べた方式の中での相対値」で、方式間の差だけに意味がある。
- 組：A＝空き22〜36（終盤の各選択率とレベル26・28・30 の中盤、空きごとに60〜150局面）、B＝空き17〜32（レベル16〜24 の中盤と終盤の各選択率、空きごとに75〜120局面）、C＝空き37〜52（レベル26・28・30 の中盤、50〜91局面、レベル36で評価）。

全セルは [cells.tsv](cells.tsv)（`set` が組、`option` が選択率か `mL`＝レベル L の中盤、`seconds` は平均時間、`discs_lost` は平均損失、`valued_by` は評価に使った探索）。
