# FFO 40〜49：Deft・Edax・Egaroucid（i3-14100）

同じ PC で、FFO 40〜49 を4つのエンジンで完全読みした。

## 条件

```sh
RUSTFLAGS="-Ctarget-cpu=native" CARGO_TARGET_DIR=target-native cargo build --locked --release -p deft_reversi_engine --example solve
python3 run.py 8
```

- 1スレッドで、全エンジンとも CPU 2 に固定した。局面ごとに新しいプロセスで解き、8周回した。エンジンの順番は、周と問題ごとに入れ替えた。表の値は8周の中央値。
- 石差は、10問すべて、全エンジン・全周で正解と一致した。
- 置換表は、Deft が 256 MiB、Edax・Egaroucid が `-h 23` / `-hash 23`。Edax と Egaroucid は定石を使わない。

| 名前 | 中身 |
|---|---|
| deft-1000 | `feature/engine-v2` の作業ツリー。新モデル（lr 0.3・8エポック）と、1,000局面の校正（測った t）を入れた1ファイル `e8-mpc.dpr2` |
| deft-legacy | 同じ重み（`e8.dpr2`）に、旧 main の規則（`--legacy-main-mpc`） |
| edax-4.5.5 | 配布版のバイナリ `lEdax-x86-64-v3`、`data/eval.dat` |
| egaroucid-7.8.1 | 配布版の `console_v7.8.1` を clang でビルドしたもの（`Egaroucid_for_Console_clang.out`） |

- 合計では、deft-legacy が最も速い（Edax の 0.86倍、Egaroucid の 0.89倍）。deft-1000 は Edax の 1.02倍、Egaroucid の 1.05倍。

## 注意

`non-native/` は、最初に `-Ctarget-cpu=native` なしでビルドした Deft で測った結果である。Deft の時間はこの表の約1.75倍だった（ノード数は同じ）。2026-10-31〜11-01 の MPC の記録の Deft の時間も、同じく native なしのビルドで測っている。Deft どうしの比較は同じビルドなので有効だが、ほかのエンジンとは比べられない。
