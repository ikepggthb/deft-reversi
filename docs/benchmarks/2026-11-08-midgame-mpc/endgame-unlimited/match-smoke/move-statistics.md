# 1手の時間・完了深さ

追加対戦なし。中央値は中央2件の平均（偶数件の場合）。85%などの基準側は全対戦相手を合算。時間の単位はms。

探索時間はエンジン内部、外側時間は探索前のTT消去等を含む。深さは最後の完了反復。終盤モードの反復が完了した場合は残り空き数を深さとし、完全読みの保証はsolved件数で区別する。
