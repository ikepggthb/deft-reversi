# 1手の時間・完了深さの分布

既存64局のログを再集計。追加対戦なし。時間の単位はms。中央値は偶数件の場合、中央2件の平均。85%は全対戦相手との基準側の着手を合算し、ほかは候補側の着手。空き19以上が中盤、18以下が共通終盤。

探索時間はエンジン内部の計測。外側時間は探索前のTT消去などを含み、GTP通信やログの最終出力・着手適用は含まない。深さは最後に完了した反復。終盤モードの反復が完了した場合は、その局面の残り空き数を深さとして集計し、完全読みの保証はsolved件数で別に表す。
