# 完全読みの MPC 規則を式で表し、浅い探索の深さを選び直す

この文書は、次の3つの変更を記録する。

1. **終盤の規則の式**：完全読みの ProbCut 規則（傾き a・切片 b・ばらつき σ）を、空きマス数 e と浅い探索の深さ s の式で表す。
2. **浅い深さの表**：完全読みの浅い探索の深さを、FFO 40〜59 の完全読みの時間で選び直す。
3. **中盤探索の切り替え**：中盤探索を、残りの深さで切り替える形（旧 main と同じ）に戻す。MPC の浅い探索は、MPC を使わない中盤探索にする。

1と2は `deft-reversi-train mpc` に入れた。学習ツールは、式の係数と段の倍数 t を測定データから当てはめる。浅い深さの表は、探索の設定として固定する。

## 1. 終盤の規則の式

### なぜ式にするのか

これまでの完全読みの規則は、空き12〜24で測った値の表だった。空き25以上では、同じ偶奇の最後の値（空き23・24）を使い回していた。

表には、測った (e, s) の組の値しかない。浅い探索の深さを変えると、その組の値がない。実際に、空き29以上では次の食い違いが起きていた。

- 浅い深さは7・8に変えていた。
- a・b・σ は、空き23・24を浅い深さ5・6で測った値のままだった。
- σ は 4.65 と 4.31 になる。深さ7・8で測った本当の値は 4.17 と 3.92 である。

式にすれば、どの (e, s) にも値が出るので、浅い深さを変えても規則が合う。

### データ

[positions-exact.tsv](positions-exact.tsv) を使った。

- 内容：v2-pattern-lr0.3 の8エポックのモデルで測った valid 分割の局面。空き12〜24マスで、それぞれ1,000局面ある。各局面について、深さ0〜14の全幅探索の値と、完全読みの値を持つ。
- 出どころ：`deft-reversi-train mpc` の `positions.tsv`（sha256 `cc7326b0…ac13d`）から、完全読みのある行だけを抜き出した。
- 使ったセル：(e, s) ごとに、`完全読み ≈ a·v_s + b` の回帰を求める。σ はその残差の標準偏差である。s は0〜14、残りの深さ r = e − s は4以上のセルだけを使う（規則が使われうる範囲）。

### 選んだ式

浅い深さの偶奇ごとに、別々に当てはめる。

```
a(e, s) = α0 + α1·e + α2·s
b(e, s) = β0 + β1·e + β2·s
σ(e, s)² = (c0 + c1·s + c2·s²) · (1 − exp(−(e − s)/λ))
```

- 当てはめは、局面数で重みを付けた最小二乗法で行う。λ は格子で探索する。
- 空き25以上では、a と b は空き24の値にする（データがない）。σ は式のまま延ばす。
- 段の倍数 t は、式で予想したときの |z| を、すべてのセル（すべての s）で並べた分位点である。
- 全データで当てはめた係数と、表にした値は [results.txt](results.txt) の6節にある。

#### 各部分の根拠

- **偶奇で別の式にする理由**
  - 浅い探索の値は、深さが奇数だと約2石高い。手番側が誤差を含んだ子の最大値を選ぶので、上に偏る（最大値を選ぶことによる偏り）。偶数の深さでは、相手の最小と手番の最大が打ち消し合う。
  - 完全読みの値には評価の誤差がないので、この偏りがそのまま切片に出る。空き24の切片は s = 2, 3, 4, 5, … で +0.38, −1.97, +0.56, −1.58, … となる。
  - 深さとの関係も偶奇で逆向きである。奇数では深くなるほど偏りが縮み、偶数では少しずつ上がる。符号を入れ替える項を1つ足すだけでは表せないので、式全体を分けた。
  - 中盤の規則では、深い探索と浅い探索の偶奇をそろえているので、偏りが差の中で消える（空き30・深さ10では、浅い深さ4・6で差の平均が −0.15・+0.05、5・7で −2.33・−2.24）。
- **(1 − exp(−r/λ))**
  - 残りの深さ r = 0 なら、浅い探索が完全読みそのものなので σ = 0 になる。r が大きくなると σ は頭打ちになる。
  - 空き18〜24では、σ がほぼ一定である。
  - この頭打ちの形は、[MPC の統計モデルの再検討](../2026-11-01-mpc-models/README.md)の G モデルから借りた。
- **(c0 + c1·s + c2·s²)**
  - 浅い探索が深いほど、σ は小さくなる。
  - 2次式にした理論的な理由はない。データに合う形として選んだ。
- **a と b は (e, s) の1次式**：確認用のデータで、これ以上の形を必要としなかった。

#### 出どころ

この式は、論文にも Edax・Egaroucid にもない。このデータの形を見て作ったものである。

候補は次の5つで、確認用のセルで比べて選んだ。

- 頭打ち付きの2次式（採用）
- 頭打ち付きの1次式
- 中盤と同じ1次式
- Edax 型の2次式
- Egaroucid 型の3次式

候補は少ないが、確認用のセルで選んだ分だけ、成績は良く見えている可能性がある。

### 確かめたこと（[fit_formula.py](fit_formula.py)、結果は [results.txt](results.txt)）

数値は、当てはめに使っていないセルでの誤差である（平均 / 二乗平均、単位は石）。

#### 空きマス数を延ばす（12〜20で当てはめ、21〜24で確認）

| | 偶数の s | 奇数の s |
|---|---|---|
| σ：採用した式 | +0.00 / 0.14 | −0.02 / 0.13 |
| σ：今の表（最後の値の使い回し） | −0.16 / 0.24 | −0.14 / 0.22 |
| σ：Edax 型の2次式 | −0.29 / 0.33 | −0.23 / 0.28 |
| σ：Egaroucid 型の3次式 | −0.34 / 0.42 | −0.32 / 0.39 |
| b：1次式 | +0.08 / 0.30 | +0.06 / 0.25 |
| b：今の表 | −0.07 / 0.28 | +0.17 / 0.29 |

- 12〜16で当てはめて17〜24で確かめると、採用した式の σ は +0.15 / 0.22（偶数）、+0.09 / 0.18（奇数）だった。
- 今の表は σ を小さめに外す。小さめの σ は、刈りすぎる側の誤りである。
- 採用した式は、大きめ（安全側）に外す。
- 傾き a の誤差は、どの場合も 0.01 程度だった。

#### 浅い探索の深さを変える

- **測った範囲の中**（各 s を1つずつ抜いて当てはめ、その s で確認）
  - s = 2〜12 では、σ の誤差は 0.06〜0.21 だった。
  - 両端の s = 0, 1, 13, 14 では、0.24〜0.40 だった。
- **測った範囲の外**（深いほうへ延ばす）
  - s ≤ 8 で当てはめて9〜14で確かめると、σ を +0.4〜0.5 大きめに外した。
  - s ≤ 6 で当てはめると、+0.4〜0.7 大きめに外した。
  - 2次式の部分は、範囲の外では信用できない。**浅い深さは、測った範囲（14以下）に限って使う。**
- **刈り間違いの率**（12〜20で当てはめ、21〜24で確認）
  - 段の倍数 t は、全部の s をまとめて決めた。
  - |z| がそれを超える割合を、s ごとに見た。98% の段（目標 0.020）では、s ごとに 0.019〜0.028 だった。
  - s = 8〜12 はやや多い（0.024〜0.028）。
  - s によって大きな片寄りはないので、t は s によらず1組とした。

### 残っていること

- **空き25以上**：データがないので、a と b は空き24の値で止めている。空き25〜28の120局面では、切片が式より 0.6〜0.7 大きかった。ただし、空き12〜24でも、120局面だけで計算すると切片が ±0.5 ほどずれる。120局面では区別がつかない。

## 2. 浅い深さの表

完全読みの速さを主な目的として選んだ。どの表でも、完全読みの答えはすべて一致した。

### 空き12〜19：1マスずつ

[tune/per_empties.py](tune/per_empties.py) を使い、ログは [tune/per-empties-log.txt](tune/per-empties-log.txt) にある。

- **局面**：valid 分割のうち、ProbCut の測定に使っていない局面を、別の乱数で選んだ（[tune/make_sets.py](tune/make_sets.py)）。
  - 空き12〜15：根が空き18の300局面
  - 空き16〜19：根が空き22の200局面
- **測り方**：1つの空きマス数だけ深さを変え、ほかは固定した。1コアで1つずつ解き、1局面ごとの時間の比の幾何平均をとった。

| 空き | 今の深さ | 比べた深さ | 結果 |
|---|---|---|---|
| 12〜15 | 4, 3, 4, 3 | 0〜4 | どの深さでも ±1.7% 以内。13・14 は深さ1で 0.8〜1.1% 速い |
| 16〜19 | 4, 5, 6, 5 | 1〜6 | どの深さでも ±1% 以内 |

このあたりでは、浅い深さは時間にほとんど効かない。空き12〜15は1にそろえ、空き16〜19は今のままとした。

### 空き20以上：FFO 40〜59

[tune/ffo_tables.py](tune/ffo_tables.py) を使い、ログは [tune/ffo-log.txt](tune/ffo-log.txt) にある。FFO 40〜59 を1コアで1回ずつ解いた。

| 空き12〜15 | 空き16〜19 | 空き20〜28 | 空き29以上 | 合計 |
|---|---|---|---|---|
| 1 | 4,5,6,5 | 6/5 | 8/7 | 313.6 s |
| 1 | 全部3 | 6/5 | 8/7 | 308.3 s |
| 1 | 全部4 | 6/5 | 8/7 | 311.4 s |
| 1 | 4,5,6,5 | 4/3 | 6/5 | 345.4 s |
| 1 | 4,5,6,5 | **8/7** | **8/7** | **300.0 s** |
| 1 | 4,5,6,5 | 8/7 | 10/9 | 300.9 s |
| 1 | 4,5,6,5 | 10/9 | 12/11 | 311.2 s |
| 1 | 4,5,6,5 | 6/5 | 10/9 | 311.5 s |

（「a/b」は、空きが偶数なら a、奇数なら b）

- 空き20以上を浅くすると、はっきり遅くなる（問題57が 34 s から 71 s）。
- 2手深くすると速くなる。それ以上深くすると戻る。
- 空き29以上は、8/7 と 10/9 で変わらない。

### 決めた表

| 空き | 浅い深さ |
|---|---|
| 12〜15 | 1 |
| 16, 17, 18, 19 | 4, 5, 6, 5 |
| 20以上 | 偶数 8、奇数 7 |

## 3. 中盤探索の切り替え

書き直し版の中盤探索（`node`）は、残りの深さが1の所だけを特別に扱い、それより上ではずっと TT と手順付けを使っていた。旧 main では、残りの深さで切り替えていた。

- 6以上：TT あり
- 4〜5：TT なし、手順付けあり
- 3：手順付けあり
- 2以下：手順付けなし

この切り替えを、旧 main と同じ形に戻した。

- **6未満**：ヌルウィンドウの中盤ノードは TT を使わない。評価値と着手可能数で手順付けする。
- **3未満**：手順付けもしない（`ordering_search`）。
- **窓が広いノード**：PV を返すので、今までどおり `node` で読む。

MPC の浅い探索は、旧 main と同じく「MPC を使わない中盤探索」（`node` に `probcut: false`）にした。これまでは、浅い探索全体を手順付けなしの `ordering_search` で読んでいた。

Edax と Egaroucid のソースも確かめた。

- **Egaroucid 7.8.1**：浅い探索の前に `mpc_level = MPC_100_LEVEL` にして、MPC を切る。
- **Edax**：浅い探索でも同じ段のまま MPC を使う（入れ子は2段まで）。

Deft の規則は MPC を使わない全幅探索の値で測っているので、Egaroucid と同じく MPC を切るのが合っている。

### 結果

同じモデル・同じ規則で比べた。1コアで1つずつ、TT は 256 MiB。

| | 変更前（a5e1513） | 変更後 | 差 |
|---|---|---|---|
| 中盤 レベル18（200局面、空き36・44） | 31.4 s | 19.5 s | −38% |
| 中盤 レベル24（同） | 699.5 s | 397.3 s | −43% |
| 完全読み end120 | 164.1 s | 157.1 s | −4.3% |
| 完全読み FFO 40〜49 | 13.6 s | 13.2 s | −3% |

- 完全読みの答えは同じだった。
- 中盤（選択的な探索）では、200局面のうち3〜5局面で評価値または手が変わった。TT の使い方が変わると手の順番が変わり、MPC で刈る場所が変わるためである。
