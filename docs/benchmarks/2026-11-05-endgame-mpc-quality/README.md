# 選択的な終盤探索（98%）の悪手を減らす（2026-11-05）

レベル12の対局（[2026-11-03-engine-match](../2026-11-03-engine-match/README.md)）を集計すると、空き22〜24（98% の選択的な終盤探索で読む範囲）で、Deft の悪手（最善から4石以上の損）が Edax より多かった（1.33% 対 0.13%）。

選んだ20局面での比較では、Edax との違いとして次の3つが挙がった。悪手10局面のうち6局面は、確認探索を深くすると直った。

- **確認探索の深さ**：空き22・23・24 で、Deft は 8・7・8、Edax は 10・11・12。
- **窓の広い探索の MPC**：Deft は使う。Edax はゼロ窓の探索でしか使わない。
- **最後の14空きの MPC**：Deft は空き12から使う。Edax は使わない。

これを、多くの局面で確かめた。

## 測り方

[tools/](tools) の `mpc-quality` を使った。

1. 各局面で、TT を空にしてから、Deft の 98% の選択的な終盤探索（`Goal::Endgame`、`Selectivity::Percent98`）で手を選ぶ。
2. その局面と、選んだ手の後の局面を、完全読みで解く（結果は保存して使い回す）。
3. 損 = その局面の値 − 選んだ手の値。4石以上の損を悪手とした。

局面は2組使った。

- **対局の局面**（[games-22-24.obf](games-22-24.obf)、1,445局面）：レベル12の対局で、Deft の手番で空き22〜24 だった局面（[game_positions.py](game_positions.py)）。
- **ランダムな局面**（[pos-22-24.obf](pos-22-24.obf)、1,800局面）：valid 分割から選んだ空き22・23・24 を各600。ProbCut の測定と、浅い深さの調整に使った局面は除いた。

モデルは `mpc-formula/model.dpr2` である。確認探索を深くした規則は、[make_rules.py](../2026-11-02-exact-mpc-formula/make_rules.py) で作った（σ は式で深さごとに決まる）。

- `deep2`：空き20以上を 10/9 手
- `edax`：空き20以上を Edax と同じ 2⌊e/4⌋ + (e の偶奇)

ほかの2つは、診断用の環境変数で切り替えた（コミットしたエンジンには含まない）。結果は [runs/](runs) にある。集計は [summarize.py](summarize.py)、[paired.py](paired.py) で行った。

## わかったこと

- **確認探索を深くしても、Deft ではほとんど変わらない。** Deft の σ は、深さごとに式で決まる。深い確認探索は σ が小さくなるので、同じ「98%」では刈る強さもほぼ同じになり、精度は上がらない。選んだ20局面で6件直ったのは、σ を変えずに深くしたので判定が慎重になったためと考える（推測）。
- **効くのは、判定を慎重にすることである。**
  - 確率を 99% に上げると、対局の局面で悪手が 16 → 11、損の平均が 0.107 → 0.078 になった（時間 1.2倍）。
  - 窓の広い探索で MPC を使わないようにすると、さらに 11 → 8、損の平均 0.055 になった（時間はほぼ同じ）。
  - 最後の14空きで MPC を使わないのも効くが、同じくらいの時間をかけるなら 99% のほうがよく効いた。
- **「98%」という名前が同じでも、エンジンごとの実際の慎重さは違う。** Deft の 98% は、Edax の 98% より刈りが強い。

## エンジンに入れた変更

**窓の広い探索で MPC を使わない**（Edax と同じ）を入れた。ゼロ窓のノードだけで ProbCut を試す。

| | 入れる前 | 入れた後 |
|---|---|---|
| 中盤 レベル21（150局面） | 51.12 s | 52.83 s |
| 中盤 レベル18 | 15.43 s | 15.30 s |
| FFO 40〜59 | 284.2 s | 281.0 s |
| レベル24 と同じ手を選ぶ割合（レベル21） | 84.0% | 84.0% |

`tests/search.rs` の `selective_preparation_cannot_supply_the_exact_final_score` は、空き13の根では ProbCut を試すノードがなくなったので、空き14から始めるようにした。期待値も、ProbCut の規則を持たない完全読みに替えた（素朴な全探索は、空き14では遅すぎるため）。

## まだ決めていないこと

選択的な終盤探索の確率を上げるか（例：レベル表の 98% を 99% にする）。上げれば悪手は減るが、その範囲の時間が約1.2倍になる。レベルの意味が変わるので、決めてから入れる。
