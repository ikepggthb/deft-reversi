# 持ち時間制：29〜32空きの終盤探索（ENTRY）に時間をかける価値

[時間管理のロードマップ](../../design/2026-11-20-time-control-roadmap.md)の追加調査。段階3-1で残った課題は「延長モードで重い ENTRY が終わらない」こと。ユーザーの問いは「60秒の対局のように時間が長いほど、終盤の完全読みや終盤 MPC を増やしたほうが強くなりそうだが、実際はどうか。時計はそれを考慮しているか」。

ENTRY は、中盤の深さ優先の読みから、終盤の読み（MPC 85% で最後まで、e85）に切り替える最初の反復。その後、e95・e98・e99 と MPC を緩め、最後は完全読み（e100）になる。

**延長した手番での手の良さを測ったもので、対局での石差ではない。** 開局は調整用の 450〜749 で、まだどの分析にも使っていない。

## 結論

- **29〜32空きの ENTRY には価値がある。1手番あたり +0.20 石 [+0.08, +0.33]。** 時計が中盤で止めると決めた手番で、そのあと ENTRY を読み切った場合の値。ENTRY で手が変わるのは 13%。重い ENTRY ほど価値が大きい（hard の3倍以上で +0.42 [+0.08, +0.75]、1倍未満で +0.07 [0.00, +0.19]）。
- **これまでの参照では、この価値が見えていなかった。** 段階3-2の参照は、29空き以上を深さ26の探索で測っている。この参照では同じ手番が +0.06 [−0.02, +0.16] で、区間は0をまたいでいた。29〜32空きの239局面を完全読みで解き直すと、上の値になった。深さ26の参照は ENTRY より浅く読むため、ENTRY が見つけた良い手を良いと判定できない。**段階4のシミュレーションも同じ参照を使っているので、29空き以上の終盤探索の価値は小さく見積もられている。**
- **ただし、時間の割には高くつく。** ENTRY は中央値 4.4 秒かかる。その手番の hard の 1.6 倍で、その時点の残り時間（中央値 7.6 秒）の 6 割にあたる。1秒あたりにすると 0.034 石/秒。20秒の対局での時間の相場は、大まかに 0.035〜0.055 石/秒（時間 10% ≈ 0.07〜0.11 石、段階4-2）。**20秒の対局で ENTRY に時間を回しても得になるとは言えない**（同じくらいか少し損）。
- **時計は「時間が長いほど終盤探索に入る」ことを、間接的に考慮している。** 時計は「次の反復が hard までに終わるか」で止めるかを決める。持ち時間が長いと hard も長くなるので、ENTRY に入る手番が自然に増える。通常の対局で終盤の反復まで終えた手番の割合を見ると、下の表のとおり。

  | 空き | 2秒 | 20秒 | 60秒 |
  |---|---|---|---|
  | 27〜28 | 1% | 81% | 86% |
  | 29〜30 | 1% | 46% | 80% |
  | 31〜32 | 0% | 8% | 60% |

  60秒では、29〜32空きの多くの手番ですでに ENTRY を終えている。ENTRY の秒数は持ち時間によらないが、時間の相場は持ち時間が長いほど安い。そのため、時間が長いほど ENTRY は割に合う。この向きは時計の今の作りと一致している。
- **時計が考慮していないこと：** 終盤の反復を中盤の反復より価値が高いとは見ていない。止めるかどうかは「時間が足りるか」と不安定度（最善手が変わったか）だけで決めている。60秒で ENTRY をもっと増やせば得になるかは、このデータでは分からない（この測定は20秒の対局）。
- **24〜28空きでは、延長しても良くならない。** 時計が終盤で止めた手番では、延長で完全読みまで読み進めても、24〜26空きは 0.000（208手番すべて）、27〜28空きは +0.09 [0.00, +0.20] で、区間は0をまたぐ。20秒の対局でも、24〜26空きは止めた時点ですでに完全読みか e99 に達していることが多い。
- **29〜32空きで ENTRY の後の段：** e99 まで進んだ手番では +0.27 [+0.04, +0.58]（52手番）。件数が少なく、区間は広い。

## 方法

| 項目 | 内容 |
|---|---|
| 対局 | `stage3.sh ... x-gtp20e`。20秒の自己対局（GTP、1スレッド）、開局 450〜749 の 300 開局 × 先後 = 600局。各局の 24〜32空きの1手番を選び、その手番は延長モード（時計の判断を記録したうえで、30秒まで読み続ける）。延長した手番で対局を打ち切る |
| バイナリ・モデル | 段階3と同じ（`deft-f4aa62f`、`model-v4.dpr2`） |
| 時間切れ | 0（延長した手番より前） |
| 参照 | 28空き以下は完全読み（段階3-2と補足 599局面）。29〜32空きは、比較のため2通り。(1) 深さ26・MPC 85%（段階3-2と同じ）、(2) 完全読み（`refer_log ... 0`、239局面、1局面あたり中央値で数分、最大 72 分） |
| 価値 | 前の反復の手の損失 − 後の反復の手の損失（石）。損失は参照の最善の値 − その手の値 |
| 区間 | 開局ごとのブートストラップ（2000回）の 95% 区間 |
| 集計 | `tools/time-control/entry_value.py summary RUN REFER x-gtp20e`（REFER はカンマ区切りで複数、先のものが優先） |

### 手番の分け方

時計が止めると決めた時点（`decision_elapsed`）で、最後に終わった反復の種類で分ける。

| 空き | 時計が中盤で止めた | うち ENTRY を終えた | 時計が終盤で止めた | 除外 |
|---|---|---|---|---|
| 24〜26 | 6 | 6 | 208 | |
| 27〜28 | 13 | 13 | 112 | |
| 29〜32 | 125 | 122 | 73 | |
| 計 | 144 | 141 | 393 | 63 |

除外の 63 手番は、最初の反復（前の手番の置換表から始めるので経過を報告しない）が、時計の止める時点を越えて終わったもの。その時点での手は置換表の手なので、比べる基準がない。最初に報告された反復は、ほとんどが終盤の段（e85 31、e95 19）。

ENTRY の時間（秒、手番の soft・hard に対する比。中央値 [10%, 90%]）：

|---|---|---|---|---|
| 24〜26 | 6 | 0.46 [0.04, 0.92] | 0.59 | 0.39 |
| 27〜28 | 13 | 1.65 [0.70, 4.31] | 1.17 | 0.59 |
| 29〜32 | 122 | 4.44 [1.97, 12.01] | 3.25 [1.19, 8.24] | 1.62 [0.60, 4.12] |

## 残った課題

- **20秒の対局で ENTRY を増やすべきかは、決められない。** 1秒あたりの価値と時間の相場がほぼ同じ。相場は段階3-2の条件ごとの損失から出した大まかな目安で、終盤から時間を取るのか中盤から取るのかで変わる。決めるには、同じ持ち時間で「29〜32空きで ENTRY を hard の数倍まで許す時計」と今の時計を対局で比べる必要がある（数百局）。
- **段階4のシミュレーションの値は、29空き以上の終盤探索について小さめ。** 4-1・4-2 の「時間の予測・価値の予測を良くしても得は小さい」という結論のうち、29〜32空きの ENTRY に関わる部分は見直しの余地がある。通常の対局の 29〜32空きの局面（数千）を完全読みで解き直せば直せるが、1局面に数分〜1時間かかる（20コアで10時間以上）。
- **60秒の対局では未測定。** 60秒ではすでに 29〜30空きの 8 割で ENTRY を終えているので、残りの手番に時間を回す余地は小さいと見込む。33空き以上での ENTRY は測っていない。

## 再現

```sh
DEFT_MODEL=$PWD/local/time-control/stage3/bin/model-v4.dpr2 tools/time-control/stage3.sh \
  local/time-control/stage3/bin/deft-f4aa62f local/time-control/stage3/run-v4 x-gtp20e
d=local/time-control/stage3
python3 tools/time-control/entry_value.py missing $d/run-v4 x-gtp20e $d/refer-v4 > $d/refer-v4/extra-x20e/positions.tsv
python3 tools/time-control/entry_value.py missing $d/run-v4 x-gtp20e | awk -F'\t' '$5>=29' > $d/refer-x20e-exact/positions.tsv
# 20プロセス：refer_log POSITIONS OUT 26 i/20（補足）、refer_log POSITIONS OUT 0 i/20（完全読み）
python3 tools/time-control/entry_value.py summary $d/run-v4 $d/refer-x20e-exact,$d/refer-v4 x-gtp20e
```

`touch run-v4/STOP` で対局を、参照探索の出力ディレクトリの `STOP` で参照探索を止め、同じコマンドで再開できる（今回は止めずに最後まで流した）。生データは `local/time-control/stage3/` に置き、git には入れない。対局は約1時間、補足の参照は約10分、完全読みの参照は約2時間40分。
