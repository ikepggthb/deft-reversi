# 全着手の時間・完了深さ・終盤移行

時間の単位はms。終盤結果の完了深さは空き数。中盤と終盤を通じた同じ100 msの予算。
移行境界到達は空き数−1の中盤反復、または終盤反復の完了。99%未完了でも、それ以前の完了結果で着手する。
99%完了には100%も完了した着手を含む。完全読み完了は100%完了だけ。
