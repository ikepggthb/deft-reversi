## わかったこと

- **変更前との比較**
  - 合計は 326.3 s から 300.7 s になった（−7.9%）。
  - 大きく速くなったのは、問題49（5.6 → 3.2 s）、52（4.9 → 3.3 s）、53（30.4 → 24.1 s）、57（39.1 → 31.3 s）である。
- **他のエンジンとの比較**
  - Edax 4.5.5（309.7 s）より 2.9% 速い。Egaroucid 7.8.1（285.9 s）より 5.2% 遅い。
  - FFO 40〜49 だけなら、3つの中で一番速い（10.9 s。Edax 13.3 s、Egaroucid 13.0 s）。
- **まだ遅い問題**
  - 57（31.3 s）と 58（25.4 s）は、Edax・Egaroucid の 1.3〜1.6倍かかる。
  - 53 と 54 も、Egaroucid より 8〜13% 遅い。
