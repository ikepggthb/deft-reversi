# FFO 40〜59：1スレッドと20スレッドで Edax・Egaroucid と比較（2026-11-07）

PEN のモデル（MPC は1,000局面で校正）の Deft を、Edax 4.5.5・Egaroucid 7.8.1 と比べた。

## 条件

```sh
./queue.sh   # = python3 run.py 1 4 3 …  と  python3 run.py 20 0-19 5 …
```

- 機械は Core Ultra 7 265K（P コア CPU 0〜7、E コア CPU 8〜19、SMT なし）。i3 で測った前回までの時間とは比べない。
- 1スレッドは CPU 4 に固定して3回、20スレッドは CPU 0〜19 で5回測り、問題ごとの中央値をとった。
- 1問ごとに新しいプロセスで解いた。エンジンの順番は、問題と回ごとに回した。1つずつ順に動かした。
- 答えは、すべて FFO の正解と一致した。
- エンジン
  - **Deft**：`0f11ef5`、`-Ctarget-cpu=native`、`examples/solve`。モデルは `mpc-pen-1000/model.dpr2`（sha256 `aa2d7cd9…1f05a8`）。TT 256 MiB。
  - **Edax 4.5.5**：配布バイナリ `lEdax-x86-64-v3`、`-h 23`、book なし。
  - **Egaroucid 7.8.1**：Console 版を公式の clang の手順でビルドしたもの、`-hash 23`、book なし。
- 結果は [t1/](t1)、[t20/](t20)（`results.tsv` が全部の解、`summary.txt` が問題ごとの中央値）にある。

## わかったこと

- **1スレッドでは Deft が一番速い。** Edax より13.1%、Egaroucid より3.9%速い。ノード数は Egaroucid の0.86倍、Edax の0.50倍。
- **20スレッドでは Egaroucid が一番速く、Deft は2.8%遅い。** Edax よりは15.8%速い。
  - 合計の差のほとんどは問題55以外から来ている。55 は Deft が速い（8.63 s 対 8.84 s）が、それを除くと Deft 12.00 s、Egaroucid 11.22 s（+7%）。
  - 特に差が大きいのは 56（1.17 対 0.85 s）、50（0.87 対 0.73 s）、42・44・52 など。
- **並列で増えるノードは、Deft のほうが多い。** 1 → 20 で、Deft は122億 → 138億（+13%）、Egaroucid は142億 → 143億（+1%）。Egaroucid は並列にしても余計な探索がほとんど増えず、そのぶん倍率が高い（10.9倍、Deft は10.2倍）。並列探索の分け方が、次に縮められる所と考えられる（推測）。
- 問題57 は 1スレッドではまだ Egaroucid の1.21倍だが、20スレッドでは1.06倍まで縮まる。
