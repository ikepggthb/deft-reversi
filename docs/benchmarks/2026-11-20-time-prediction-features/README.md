# 時間管理の予測：効く特徴量の分析（2026-11-20、ロードマップ段階1）

`docs/design/2026-11-20-time-control-roadmap.md` の段階1。今あるデータだけで、時間管理の各予測（次の反復の時間、将来の手番の時間、次の反復の価値）にどの特徴量が効くかを調べた。新しい対局や計測はしていない。

## 結論

| 予測 | 今の式の問題 | 効く特徴量 | 効かない特徴量 |
|---|---|---|---|
| 中盤→中盤の時間 | **定数より外れる**（RMSE 0.92〜0.95 と 0.62〜0.72）。直前の比をそのまま使うが、実際は逆戻りする | 前の比（係数 −0.33〜−0.39）、空き数、深さ、直前の時間 | 合法手の数、偶奇、隅、評価値 |
| ENTRY（中盤 → 終盤の最初のステージ） | 空き数しか使わない。対局中・4スレッドでは多く見積もる（偏り −0.29、−0.62） | 直前の時間（係数 −0.26〜−0.33：時間は直前の時間の約0.7乗で増える）、空き数、深さ、前の比 | 盤面の特徴量 |
| EXACT（選択的ステージ → 完全読み） | 対局中は大きく多く見積もる（20秒 −0.63、60秒 −0.83、4スレッド −0.93。約2〜2.5倍） | 直前の時間（係数 −0.49）、空き数、手番側の合法手の数（+0.11/手） | 直前のステージ |
| ステージ間 | 1.25 は大きすぎる（偏り −0.09〜−0.22） | 定数で十分（直前の時間が少し効く） | 空き数、ステージ、盤面 |
| 将来の手番の時間（予約） | 実際は見積もりの 0.2〜0.4倍（1スレッド）、約0.1倍（4スレッド） | **前の自分の手番の使用時間**（係数 0.65〜0.90）、その手番で完全読みに届いたか（約 ×0.25〜0.3） | — |
| 次の反復の価値 | 不安定度（最善手の変化）だけ | 最善手が変わったか（予測上位20%の平均の得 0.26石、下位20% 0.04石） | 評価値の変化量、変わった回数、評価値、盤面。説明できる分は全体で R² 約1% |

- 時間の予測の誤差（ln の RMSE）は、特徴量を足しても 0.45〜0.63 が残る。予測は分布（幅）として扱う必要がある。
- 予測の偏りは、置換表の状態（空か、前の手番の読みで温まっているか）とスレッド数で大きく変わる。どちらもログに残して特徴量にする必要がある。
- ノード数は、probe のデータに入っていないため調べていない。

## 方法

| データ | 内容 |
|---|---|
| probe | `2026-11-20-time-allocation-loss-table`（64局）と `2026-11-20-time-stopping-oracle`（200局）の2,639局面。置換表を空にして1スレッド、6秒まで |
| 参照 | 同じ局面の `refer` の値（価値の分析だけで使用） |
| 対局ログ | `2026-11-20-time-control-forecast` の評価対局（`0c53a14`）の GTP ログ：2秒・20秒・60秒（1スレッド）、20秒（4スレッド） |

- 時間の予測の正解は ln(次の反復の時間 / 直前の反復の時間)。直前の反復が10ms以上の行だけを使う。
- 評価は、偶数番と奇数番の局での交差検証。
- 次の反復が終わらなかった行（打ち切り）は、Tobit（打ち切りを下限として扱う回帰）でも確かめた。結論は通常の最小二乗と変わらない。
- 対局ログでは、Forecast で止めた手番の次の反復は始まっていないので使えない。特徴量で選ばれた欠けなので、特徴量を条件にした当てはめには偏りを生まない。

```sh
T=tools/time-control
python3 $T/features.py LOSS_TABLE/{games,probe}.txt --offset 1000 ORACLE/{games,probe}.txt > table.tsv
python3 $T/cost_fit.py table.tsv                              # cost-probe.txt
python3 $T/logtable.py LOG_DIR/new-*.log > log.tsv
python3 $T/cost_fit.py log.tsv --no-board                     # cost-games.txt
python3 $T/reserve_fit.py LOG_DIR/new-*.log                   # reserve.txt
python3 $T/value_fit.py table.tsv REF                         # value.txt（REF は refer の出力、同じ局番号の付け方）
```

## ファイル

| ファイル | 内容 |
|---|---|
| `cost-probe.txt` | probe での遷移ごとの時間の予測（今の式、定数、特徴量を足したモデル） |
| `cost-games.txt` | 対局ログでの同じ分析（2秒、20秒、60秒、20秒・4スレッドの順） |
| `reserve.txt` | 将来の手番の時間と予約の見積もり |
| `value.txt` | 次の反復で減る損失の予測 |
