# 局所TT候補手保存の前後比較

FFO 40〜49の10局面を5周、各局面で新プロセスと空のTTを使用し、前後の実行順を周ごとに逆転した。1スレッド、CPU 0固定、主TT 256 MiB、旧mainのMPC、同一の変換モデル。AMD EPYC 9V74仮想環境、Rust 1.99.1、native release。ビルド・テストは計時中に並行実行していない。

変更前は現在のソースのうち `search/tail.rs` と `search/session.rs` だけを HEAD の内容に戻したコピーから、同じツールチェーンでビルドした。MPC設定・モデル変換・その他のコードは同一。変更後は局所TTに候補手を保存し、局所探索の候補点へ加点する版。照会の重複削減・深さ別手順付け・汎用探索のTT手先行は含まない。

各周の10局面合計の中央値は25.144475秒から24.543173秒、時間2.39%短縮、速度比1.0245倍。5周中4周で変更後が短かった。ノード数は816,503,705から816,409,311（約0.012%減）とほぼ同じであり、探索量削減による大きな改善とは言えない。仮想CPUの変動やバイナリ配置の影響をこの測定だけで分離してはいない。
