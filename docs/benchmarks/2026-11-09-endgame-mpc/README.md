# 終盤MPCの確率と中盤83%の深さ：着手精度と時間（空き14〜24）

空き数ごとに、`Endgame` を各選択確率で探索した場合と、中盤83%で深さ1から1手ずつ深めた場合で、選んだ手の精度と時間を比べた。測定は当時の `tools/bench/endgame_mpc.py` と `deft-reversi-engine/examples/endgame_mpc.rs`（どちらも 2026-11-14 に削除。コードはリポジトリにもこのフォルダにも残っていない）。

## 条件

- 局面：Egaroucid学習データ（rdg形式）の test 分割から、空き14〜24の各200局面、計2,200局面。合法手2つ以上、対称形で重複なし、seed 1。MPCの校正は valid 分割なので重ならない。局面ファイルは学習データの再配布になるため置かない（測定ツールを削除したので、同じコマンドでは再生成できない）。
- モデル：model-v3-pen（sha256 `aa2d7cd9…1f05a8`）、校正値はモデル収録のまま。中盤83%は85%段階の倍率を 1.2691755 に置き換えた（[2026-11-09-midgame-mpc-79-87](../2026-11-09-midgame-mpc-79-87/README.md) と同じ値）。今のエンジンには83%の段が正式にあり、モデルの校正が同じ倍率を持つ。置き換えたビルドと今のエンジンが同じ手を指すことは [2026-11-15-level-table](../2026-11-15-level-table/README.md) の §7 で確認した。
- 計時：i3-14100、1スレッド、TT 64 MiB、CPU 2に固定、探索ごとにTT消去。
  - 終盤：`Endgame` を68/77/85/95/98/99%と100%（完全読み）で、それぞれ単独に探索（68%・77%は当時の段。今のエンジンでは選べない）。時間には `Endgame` 内部の準備探索を含む。
  - 中盤：`Depth(空き数−1)` を時間制限付きで1回探索し、深さ1から1手ずつの各反復の手と累積時間を記録（時間制限付きの探索を1手ずつ深める動作は当時の測定用で、今のエンジンは5か6から2手ずつ）。時間上限は同じ局面の最も遅い終盤探索の2倍（200 ms〜120 s）。上限で打ち切られた6局面（空き20・21・23・24）は、上限を50倍にして全段階を測り直した。
- 正解：計時の後で、各局面と、どれかの探索が選んだ手を8スレッドで完全読み。損失＝最善の石差−選んだ手の石差（石）。全合法手を完全読みした場合と、試験の12局面で一致を確認。

- 終盤68%・77%と同程度の損失になる中盤の深さは、空き17〜22でおよそ深さ11〜21（[report.md](report.md) の「同等の中盤深さ」列）。68%と77%は85%より損失が大きく、時間の差は小さい。

## 注意

- 損失の平均は200局面で、95%区間は±0.1石前後ある。95%と98%、98%と99%の差はこの区間内のことが多い。
- 中盤の時間は反復深化の累積、終盤は単独探索。対局中のように中盤反復の後でTTを共有して終盤へ移る場合の時間は測っていない。
- 1スレッド・このマシンでの時間比。時間の絶対値は他のマシンの結果と比べない。
