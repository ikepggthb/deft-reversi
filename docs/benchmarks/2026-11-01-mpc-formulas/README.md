# MPC の式の比較

ProbCut の規則（傾き・切片・deviation）を、どの式で表すのがよいかを比べた。[裾の重さの修正](../2026-11-01-mpc-tails/README.md)で、段ごとの t は実測から決めるようになった。そこで比べるのは、t を決めた後に、空きマス数・深さのどの組でも同じように刈れるか、と、測っていない所への外挿が正しいかである。

## データ

- 1,000局面の測定（[前回](../2026-11-01-mpc-tails/README.md#測定)）。空き12〜52マスで41,000局面。深さ0〜14の値と、空き12〜24マスの完全読みの値がある。
- 追加の測定：空き25〜28マスの完全読みを各120局面（計480局面）。

  ```sh
  deft-reversi-train mpc -m e8.dpr2 --data egaroucid_rd_data_set --out mpc-exact25-28 \
    --positions 120 --empties 25..=28 --exact-empties 25..=28 --max-depth 14 -t 8
  ```

  8スレッドで1時間55分。空き28マスは1局面あたり約5分かかった（1スレッド、枝刈りなし）。この局面で、外挿を直接確かめる。

## 比べた式

| | 平均（傾き・切片） | deviation |
|---|---|---|
| A 今の方法 | 組ごとの直線。中盤は (空き, 深さ, 浅い深さ) の1次式、完全読みは表 | 中盤は同じ1次式で、測った範囲に収める。完全読みは空きマス数ごとの表で、測っていない空きマス数は同じ偶奇の最後の値を使う |
| B Edax 型 | 共通の式（下記） | 3つの量の1次式 u を入れた2次式 |
| C Egaroucid 型 | 共通の式 | 同じく u を入れた3次式。完全読みの組の重みを10倍 |
| D 対数線形 | 共通の式 | log σ を、空き・その2乗・浅い深さ・その2乗・log(深さの差)・偶奇・完全読みかどうかの1次式で表す。全組の正規分布の尤度で当てはめる |
| E G の式 | 共通の式 | Var = G(e, s) − G(e, d)。G(e, e) = 0 なので、完全読みは d = e の場合 |

- 共通の平均の式は、傾きと切片を、空き・深さ・浅い深さ・偶奇・完全読みかどうかの1次式で表す。
- E の G(e, k) は、深さ k で読んだ値の、完全読みの値からの分散である。残りの手数 r = e − k − 1 とすると、G = A(e, k) · (1 − exp(−r / λ(k)))。A と λ は空き・深さ・偶奇の式で表す。
  - 最初は、残り手数のべき乗の形で試したが、合わなかった。
  - 完全読みした局面で G を直接測ると、残り1手あたり約3ずつ増え、深さで決まる値で頭打ちになる（`check_additivity.py` の出力の前に描いた表）。それに合わせて形を直した。
- 局面の番号が偶数の半分で当てはめ、奇数の半分で確かめた。B〜E は、組ごとの分散（E）または標準偏差（B・C）に当てはめた。

## 式と計算方法

係数は、局面番号が偶数の半分で当てはめた値である（[coefficients.txt](coefficients.txt)、`coefficients.py`）。記号は次のとおり。

- e：空きマス数
- d：深い探索の深さ（完全読みは d = e）
- s：浅い探索の深さ
- v：浅い探索の値
- x：完全読みなら 1、中盤なら 0
- e′ = e/60、s′ = s/60、odd(s)：s が奇数なら 1

### エンジンが規則をどう使うか

規則は、(x, d, e) ごとに、傾き a・切片 b・σ の3つの数を持つ。

- 深い値の予想は a·v + b、誤差の幅は σ である。
- 段の倍率を t（[測った値](../2026-11-01-mpc-tails/README.md#測った-t)、例えば中盤の 85% なら 1.330）とする。探索の窓 [α, β] に対して、浅い探索を null window で行う。
  - 上側：v ≥ ⌈(β − b + t·σ) / a⌉ なら、β で刈る。
  - 下側：v ≤ ⌊(α − b − t·σ) / a⌋ なら、α で刈る。
- 5つの式の違いは、この a・b・σ をどう作るかだけである。

### A 今の方法

1. 組 (x, d, e) ごとに、測った (v, 深い値) の組に最小二乗で直線を引き、a・b と残差の標準偏差 σ を求める。
2. 中盤：組ごとの a・b・σ を、それぞれ [1, e, d, s] の1次式で回帰する。
   - a = 1.0082 − 0.0008·e + 0.0001·d + 0.0048·s
   - b = −0.6739 + 0.0078·e − 0.0429·d + 0.2009·s
   - σ = 5.0219 − 0.0563·e + 0.1823·d − 0.5423·s。結果は、測った範囲 [2.103, 5.597] に収める。
3. 完全読み：組ごとの値をそのまま表にする（例：e = 24 は a 1.0533・b +0.800・σ 4.497）。表にない e は、同じ偶奇で最後に測った e の値を使う（e = 26 なら e = 24 の値）。

### B〜E の共通部分：平均（a と b）

特徴 f = [1, e′, d′, s′, odd(s), x, x·odd(s), x·e′, x·e′²] の1次式で、a = Σ αᵢ fᵢ、b = Σ βᵢ fᵢ とする。全組の「深い値 ≈ a·v + b」を最小二乗で当てはめる。

| 特徴 | α（傾き） | β（切片） |
|---|---:|---:|
| 1 | +1.0041 | −0.6641 |
| e′ | −0.0412 | +0.4759 |
| d′ | +0.0363 | −1.1395 |
| s′ | +0.2220 | +7.9506 |
| odd(s) | −0.0015 | −0.1769 |
| x | −0.0333 | −1.5981 |
| x·odd(s) | +0.0051 | −2.2640 |
| x·e′ | +0.1227 | +16.8734 |
| x·e′² | −0.0072 | −27.2244 |

### B Edax 型

- u = p₀·e + p₁·d + p₂·s、σ = p₃·u² + p₄·u + p₅
- p = (0.0476, −0.1503, 0.4516, 0.0572, −1.3077, 5.0992)
- 当てはめ：組ごとの残差の標準偏差に、組の局面数を重みにした最小二乗で合わせる（Levenberg–Marquardt）。

### C Egaroucid 型

- u = p₀·(64 − e)/64 + p₁·s/60 + p₂·d/60、σ = p₃·u³ + p₄·u² + p₅·u + p₆
- p = (0.6933, −5.3685, 1.6878, 3.7216, −3.3991, 6.0790, 1.5258)
- 当てはめ：B と同じ。ただし、完全読みの組の重みを10倍にする。

### D 対数線形

- log σ = Σ gᵢ fᵢ
- f = [1, e′, e′², s′, s′², log(d − s), odd(s), odd(s)·s′, x, x·e′, x·s′]
- g = (1.3677, −0.5053, −0.3866, −8.3855, 37.8165, 0.2929, 0.0082, 0.2416, 0.1475, 0.0081, −1.7782)
- 当てはめ：全組の残差 r に、正規分布の尤度 Σ [log σ + r²/(2σ²)] を最小にする g を、ニュートン法で求める。

### E G の式

- G(e, k) = A(e, k) · (1 − exp(−r/λ(k)))。r = e − k − 1 は、深さ k の探索の外に残る手数である。
- log A = q₀ + q₁·k/10 + q₂·e′ + q₃·e′² + q₄·(k/10)·e′ + q₅·odd(k)
- λ = exp(q₆ + q₇·k/10)
- σ² = G(e, s) − G(e, d)。完全読みは d = e で r = −1 → 0 とするので、G(e, e) = 0 となり σ² = G(e, s)。
- q = (4.3419, −0.9796, −1.4574, −0.5691, −1.4638, 0.0250, 1.9859, −0.4335)
- 当てはめ：組ごとの残差の分散の対数に、log(G(e,s) − G(e,d)) を、組の局面数を重みにした最小二乗で合わせる。

### 計算例

**中盤、e = 30・d = 10・s = 2、v = +8**

- A：a = 0.9948、b = −0.467 なので、予想は 7.49、σ = 4.072。
  - 85% の段（t = 1.330）で β = 0 なら、上側の刈りは v ≥ ⌈(0 + 0.467 + 1.330 × 4.072) / 0.9948⌉ = ⌈5.91⌉ = 6 で起こる。
- 5つの式の σ：A 4.072、B 4.056、C 4.022、D 4.015、E 4.091。中盤では、どの式もほぼ同じになる。

**完全読み、e = 26・s = 6、v = +8**

| 式 | 計算 | 予想 | σ |
|---|---|---:|---:|
| A | 表に26がないので、e = 24 の値を使う。8 × 1.0533 + 0.800 | 9.23 | 4.497 |
| B | 共通の平均 a = 1.0426・b = +0.445。u = 0.0476·26 − 0.1503·26 + 0.4516·6 = 0.039 で、σ = 0.0572·u² − 1.3077·u + 5.0992 | 8.79 | 5.048 |
| C | u = 0.6933·38/64 − 5.3685·0.1 + 1.6878·26/60 = 0.606 で、σ = 3.7216·u³ − 3.3991·u² + 6.079·u + 1.5258 | 8.79 | 4.791 |
| D | log σ = 1.3677 − 0.5053·0.433 − 0.3866·0.188 − 8.3855·0.1 + 37.8165·0.01 + 0.2929·log 20 + 0.1475 + 0.0081·0.433 − 1.7782·0.1 = 1.466 | 8.79 | 4.334 |
| E | log A(26, 6) = 2.635 で A = 13.95。λ = 5.62、r = 19 なので、G = 13.95 × (1 − e^(−19/5.62)) = 13.47。σ = √13.47 | 8.79 | 3.670 |

実測（空き26の120局面）では、予想の誤差の標準偏差は 3.85 で、平均の切片は +1.32（1,000局面で補正した値）だった。

## 結果

全部の数字は [results.txt](results.txt)、スクリプトは `compare_formulas.py`。

### 測った範囲（当てはめに使っていない半分）

t は、当てはめに使った半分で、中盤と完全読みで別々に測った。そのうえで確かめた半分では、どの式でも、全体で誤差が t を超えた割合はほぼ想定どおりになった（例えば中盤の 85% の段で 0.148〜0.149、想定 0.15）。正規分布の尤度の差も 0.003 以内である。

差が出たのは、組ごとのそろい方である。空きマス数・深さの組ごとに、85%・98% の段で誤差が t を超えた割合を出し、想定との相対誤差の二乗平均を求めた。

| | 中盤 85% | 中盤 98% | 完全読み 85% | 完全読み 98% |
|---|---:|---:|---:|---:|
| A 今の方法 | 0.182 | 0.358 | 0.182 | 0.439 |
| B Edax 型 | 0.178 | 0.360 | 0.224 | 0.576 |
| C Egaroucid 型 | 0.176 | 0.354 | 0.196 | 0.454 |
| D 対数線形 | 0.174 | 0.355 | 0.159 | 0.342 |
| E G の式 | **0.150** | **0.341** | **0.155** | **0.329** |
| （局面数による下限） | 0.107 | 0.31 | 0.10 | 0.30 |

- 1つの組の確認用の局面は約500なので、組ごとの割合にはそれだけで上の下限ほどのばらつきが出る。
- E がいちばんそろっていて、下限に近い。ただし、どの式でも差は小さい。

### G の仮定

完全読みした局面で、Var(v_d − v_s) と G(s) − G(d) を直接比べた（[additivity.txt](additivity.txt)）。比は 0.88〜1.20 で、多くは 0.95〜1.15 だった。浅い探索の誤差に深い探索の誤差が上乗せされる、という仮定はおおむね成り立つ。

## 考察：なぜこうなったか

確かめに使った数字は [why.txt](why.txt)（`why.py`）。

### 1. t を決めると、どの式でも全体の刈り方が同じになる理由

- t は、中盤と完全読みでそれぞれ1つの倍率である。σ 全体の大きさの見積もり違いは、t がそのまま吸収する。式が違って効くのは、組どうしの σ の比だけである。
- その比を決めている要因は少ない。主なものは浅い探索の深さで、空き24マスで深さ s を 0 → 7 にすると、誤差は 4.6 → 2.8 石と単調に減る（why.txt 7）。どの式もこの項を持っているので、比はほぼ同じになる。中盤の σ がのこぎり状に見えるのは、参照実装の表で浅い深さが深さごとに上下するためで、σ の式の違いではない。
- 正規分布からの外れ（裾の重さ）は、組によらない共通の形である。誤差の尖度は 8.5（正規分布なら 3）ある。局面の点差の大きさ（|浅い値|）ごとに σ を補正しても、尖度は 8.54 → 8.46 とほとんど変わらなかった（why.txt 11）。
  - 裾は、点差の大きい局面に集まっているわけではない。どの組にもまれに大きな読み違いが混ざっていて、それが裾になっている。読みの深さの外に大きな手（隅など）が隠れている、という可能性が考えられるが、確かめてはいない。
  - いずれにしても、σ の式では裾を直せない。共通の形なので、t の校正で一度に直る。

### 2. E が測った範囲で最もそろう理由

- E は、組どうしの関係を仕組みから決めている。浅い探索の誤差に、深い探索の誤差が上乗せされる、という関係である。
- この関係は、データでおおむね成り立っていた（比の中央値は空き12〜21で 1.05〜1.19、22〜28で 0.89〜1.08、why.txt 4）。
- そのため、少ない係数で組どうしの σ の比を決められ、組ごとの偶然のばらつきを拾いにくい。

### 3. E が空き25マス以上で刈りすぎた理由

- 中盤の誤差の大きさは、その空きマス数での点差の散らばりにほぼ比例する（why.txt 9）。
  - 散らばり（深さ14の値の標準偏差）は、空き30マスまでは約25石で一定である。空き40で 20、空き52で 14 と、序盤ほど小さい。序盤ほど勝負がまだ決まっておらず、点差が小さいためである。
  - 誤差との比は、どの空きマス数でも 0.16〜0.20 だった。
- E は、G の空きマス数による変化を、1本の滑らかな式（空きマス数の2次式）で表した。この式は、空き40〜52で誤差が小さくなるのに合わせて曲がる。その曲がりが空き25〜30まで及び、実際には一定のところで σ が下がり始めた。
- 同じ理由で、空き25〜28の deviation を実測より 5〜17% 小さく見積もり、刈りすぎになった。

### 4. B・C が完全読みで慎重すぎた理由

- B・C は、完全読みを「深さ = 空きマス数」の中盤として、同じ曲面に乗せる。
- 中盤のデータは深さ14までしかないので、深さ12〜28の完全読みは、曲面の端か外になる。その端の曲がりがそのまま延び、空きマス数とともに σ が増え続けた（図3）。実測の σ は、空き18以上でほぼ一定である。

### 5. A が空き25〜28で当たった理由と、空き29以上で外れる見込み

- 空き18以上の完全読みでは、浅い深さは 5・6 で、残りの手数は 11 手以上ある。G はもう頭打ちになっていて（頭打ちの目安 λ は 3〜5 手）、点差の散らばりも一定である。
- そのため、σ は空きマス数によらずほぼ一定になる。同じ偶奇の最後の値を使い回す A のやり方は、この範囲では仕組みの上でも正しい。
- ただし、空き29以上では、浅い深さが 7・8 に変わる。それでも A は、浅い深さ 5・6 の σ（4.4〜4.7）を使い回す。
- 実測では、空き25〜28で深さ7・8の探索の値から予想したときの σ は、深さ7で 4.19、深さ8で 3.52 だった（proposal.txt）。空き29以上の A は、σ を 10〜30% 大きく見積もり（4.78 対 4.19、4.50 対 3.52）、慎重すぎになっているはずである。

### 6. 切片が偶奇で入れ替わる理由

浅い探索の値の偏り（完全読み − 深さ k の値の平均）は、空き12〜24では、k が奇数だと −0.2〜−2.5、偶数だと −0.2〜+0.9 だった。表は why.txt 1。

- 奇数の深さでは、最後の手を指すのは根の側である。根の側は、誤差を含む評価値の中から最大のものを選ぶ。最大のものを選ぶと、たまたま高く出た値を選びやすいので、根の側を高く見積もる。そのため、完全読み − 探索値が負になる。
- 偶数の深さでは、最後の手は相手が最小を選ぶ。そのため、少し低く見積もる。
- 偏りの大きさは、k が深いほど小さくなる（空き20で、k = 1 が −2.15、k = 13 が −1.05）。
- 偶数側の偏りが小さいのは、評価関数そのものの平均のずれが重なっているためと考えられる。これは確かめていない。

### 7. 空き25マスで切片がずれた理由

- **半分は、120局面の選び方の偶然だった。** 空き25の120局面では、深さ14と深さ5の値の差の平均が −1.21 だった。同じ空きマス数の1,000局面全体では −1.82 で、たまたま浅い探索の値が高い局面に偏っていた。空き27も同じで、−1.58 と −1.98 だった（why.txt 8）。
- 補正の計算は、完全読み − 浅い値 = (完全読み − 深さ14の値) + (深さ14の値 − 浅い値) と分けて行う。前の項は120局面で、後ろの項は1,000局面で平均する。
- 補正後の平均の切片（共通の傾き 1.0263 で計算、[proposal.txt](proposal.txt)）は、奇数の空きマスで空き18〜24が −1.68、25〜28が −0.98 だった。偶数では +0.72 と +1.43 である。120局面だけで求めると、奇数は約 −0.4 だった。
- **補正しても、空き25〜28は空き24までより約 0.7 高い。** その中身は2つに分かれる。
  - 完全読み − 深さ14の値は、空きマス数とともになだらかに増える（空き16で −0.05、20で +0.27、24で +0.84、25〜28の120局面で +0.85〜+1.21）。
  - 一方、深さ14の値 − 浅い値は、空き18〜24では空きマス数とともに減り（例えば深さ5で、空き19の −1.72 から空き23の −2.25）、2つが打ち消し合って、空き24までの切片はほぼ一定に見えていた。空き25以上では、後ろの項の減りが止まった（深さ5で空き25〜32が −1.8〜−2.3）ので、前の項の増えた分が切片に出た。
  - ただし、後ろの項は空きマス数ごとに ±0.3 ほどばらつき、なぜ空き24を境に減りが止まるのかまでは分からない。
- 120局面なので、空き25〜28の切片にはそれぞれ ±0.3 ほどの誤差がある。4つの空きマス数を偶奇ごとに平均すると ±0.2 程度になる。

## わかったこと

- 段ごとの t を実測から決めた後では、どの式でも全体の刈り方はほぼ名前どおりになる。式による差は、組ごとのそろい方と外挿に出るが、小さい。
- G の考え方は成り立ち、測った範囲では最もそろった規則になる。ただし、空き25マス以上の完全読みへの外挿では刈りすぎになった。測っていない所を任せられる式ではない。
- 空き25マス以上の完全読みでは、平均（切片）が空き24マスまでと違う。どの式でも、空き24マスまでのデータからは予測できなかった。

## 結論と次にやること

- 式は今の方法（A）のままにする。D・E にしても、測った範囲での改善は小さく、外挿はよくならない。
- 代わりに、完全読みの規則を次のように直す（`proposal.py`・[proposal.txt](proposal.txt)）。
