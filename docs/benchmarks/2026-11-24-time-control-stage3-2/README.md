# 持ち時間制：段階3-2 の参照探索（全手番の最善手と、各反復が選んだ手の損失）

時間管理の予測を精度よくする作業（[ロードマップ](../../design/2026-11-20-time-control-roadmap.md)）の段階3-2。段階3-1 の対局（[記録](../2026-11-23-time-control-stage3/README.md)）で探索したすべての手番について、最善手と、各反復が選んだ手の値を参照探索で求めた。段階4-1（一局を通したシミュレーション）と、価値のモデル（B1〜B3）の当てはめで「正解」として使う。

## 結論

- **20,561局面をすべて読んだ**（取りこぼし0、2時間51分）。各反復が選んだ手の損失を、通常の対局の48,180手番と、延長した手番1,188（うち時計が止めると判断した手番1,139）について出した。実際に指した手で参照の値がない手番は0件だった。
- **指した手の損失（参照に対して、1局・片方あたり）**は、GTP 2秒で 4.0 石、FlipSight 6秒で 2.8 石、GTP 20秒で 1.6 石、GTP 60秒で 0.87 石、GTP 20秒・4スレッドで 0.74 石。20空き以下はどの条件でも0（完全読みが間に合っている）。損失のほとんどは21空き以上で出ている。
- **ENTRY（中盤から終盤の読みへ移る反復）は、1回で平均 1.0〜1.4 石の損失を減らす。** 中盤の反復1回（0.10〜0.16 石）の約10倍。ただし、通常の対局で終わった ENTRY は、時計が「間に合う」と見て始めた軽いものに偏っている。
- **時計が止めた所で止めても、損は見えなかった。** 延長した手番で、時計が止めると判断した時点の手と、延長の最後の手の損失の差は、4条件とも 0.00〜0.05 石で、95%区間はどれも0をまたぐ。判断の後に手が変わったのは、2秒で9%、ほかの3条件で2%。判断の後に終わった ENTRY・選択的ステージ・EXACT（条件ごとに14〜77回）は、手を一度も良くしなかった。
- **中盤の参照は深さ26なので、深い中盤の損失はあてにならない。** 60秒と4スレッドでは、中盤の反復の約16%が深さ23以上で、最大は深さ32（参照より深い）。29空き以上の損失は「深さ26の探索との差」と読む。

## 条件

| 項目 | 内容 |

| 局面 | 同じ局面は1回だけ読む（色を入れ替えた2局はほぼ同じ棋譜になる）。20,561局面：28空き以下 13,027、29〜40空き 4,982、41空き以上 2,552 |
| 参照 | 28空き以下は完全読み。それより多い局面は深さ26・MPC 85%（`Selectivity::Percent85`）。まず制限なしで読んで最善手と値を出し、反復が選んだほかの手は `root_moves` で1手ずつ読む |
| 時間 | 2026-11-23 22:26:57 〜 11-24 01:18:18。1局面の平均は、28空き以下 3.1 s、29〜40空き 11.3 s、41空き以上 27.4 s |

コマンド：

```
DEFT_MODEL=local/time-control/stage3/bin/model-v4.dpr2 \
  tools/time-control/stage3_refer.sh local/time-control/stage3/run-v4 local/time-control/stage3/refer-v4
tools/time-control/refer_loss.py table run-v4 refer-v4 > refer-v4/iterations.tsv   # 反復ごとの損失（159,051行）
tools/time-control/refer_loss.py summary refer-v4/iterations.tsv > summary.txt
```

`touch OUT_DIR/STOP` で各プロセスが今の局面を終えてから止まり、同じコマンドで続きから再開する（今回は止めずに最後まで流した）。参照の結果（`refer-v4/out-*.tsv`）と反復の表は `local/time-control/stage3/` に置き、git には入れない。

損失は「参照の最善手の値 − その手の値」（石）。区間は、開局を単位にしたブートストラップ（2,000回）の95%区間。

## 考察

- 段階2の結論（[特徴量の分析](../2026-11-20-time-prediction-features/README.md)）「価値は最善手の変化以外ほぼ効かない」と合う。時計が止める所では、次の反復の価値はすでにほぼ0になっている。
- 一方で、ENTRY を最後まで読めた手番では1回平均 1.0〜1.4 石の値がある。延長で判断の後に終わった ENTRY が手を良くしなかったのは、件数が少ない（14〜38）うえに、終わったのは軽いものだけで、重い ENTRY の約7割は延長の上限までに終わらなかった（段階3-1）。「止めた ENTRY に価値がない」とはまだ言えない。
- 損失の大部分は21〜40空きで出ている。20空き以下は全条件で0なので、時間の配分を変えても伸びる余地はない。

## 残った課題

1. **重い ENTRY の価値が測れていない。** 延長の上限までに終わらなかった ENTRY は、そこで打ち切られたので値がない。段階3-1 の課題1（ENTRY を狙った追加の延長：20秒の対局、延長 30 s、空き 24〜32）を流せば、ここも埋まる。その局面の参照探索は28空き以下が多いので、数分で終わる。
2. 29空き以上の損失は深さ26の参照との差なので、深い中盤の反復（深さ23以上、60秒と4スレッドで約16%）の値は小さく出る。B1〜B3 の当てはめでは、段階2と同じく深さ22を超える中盤の反復を除くか、別に扱う。
3. 次は段階4-1（一局を通したシミュレーション）。反復の時間（段階3-1）と、この表の損失を使う。
