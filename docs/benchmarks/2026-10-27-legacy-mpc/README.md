# 旧mainのMPCと1コア終盤測定

`main` の `deft-reversi-engine/src/mpc.rs`（コミット `5a17bdce`）には、終盤MPCの局面別係数表がある。旧 `eval.json` 自体には係数は入っていない。中盤の回帰式は現行既定値と一致するが、終盤は現行の回帰式ではなく、12〜20空きの個別値と21空き以降の再利用値を使う。`Engine::set_legacy_main_mpc` とsolve例の `--legacy-main-mpc` で明示的にこの設定を使用できる。

## 3エンジンの参考比較

FFO 40〜44、1スレッド、各局面ごとに新プロセス、CPU 0に固定し、エンジンの順番を周ごとに巡回して5周した。探索時間の局面合計の中央値:

| エンジン | 秒 |
|---|---:|
| deft、旧mainのMPC | 3.546 |
| Edax | 3.133 |
| Egaroucid | 2.769 |

全75実行でスコアは38、0、6、-12、-14に一致し、終盤の深さまで探索した。Egaroucidは100%と表示し、Edaxは非選択的な結果として表示した。`deft-three-way-baseline.tsv` は全測定。NPSやノード数はエンジン間で定義が異なるため、直接比較しない。

AMD EPYC 9V74仮想環境。deftは `8ab1682` に旧mainのMPC設定を追加した版、Rust 1.99.1、native release、主TT 256 MiBとPV TT 16 MiB。Edaxは `786421f`、GCC 14.2、`-Ofast -flto -march=native`、`-n 1 -l 60 -h 23`。Egaroucidは `2a65c87`、G++ 14.2、`-O3 -flto -march=native -DHAS_AMD_PROCESSOR`、`-t 1 -l 60 -nobook -hash 23`。エンジンごとに評価器、TT構成、準備探索、PVの仕様は異なる。Egaroucidのhash23ファイルがないため、その実装の乱数によるフォールバックを使用した。評価ファイルの読込と初期化は計時外。仮想CPU上の測定であり、他CPUへ倍率を一般化しない。

ソース内の測定スクリプト `compare-three.py` は今回のワークスペースのパスと `/tmp` の変換モデルを使用する記録用スクリプト。バイナリSHA-256: deft `220a4a196faa0f9ea34612662f831d3d37b54c2485e2fdabc09b69e9c5f58301`、Edax `a9b8c64891781832aadf89df938f2a377b9abfc62f9b2b740607bc03274d0ad9`、Egaroucid `80fdd6999eb2a66b269b83ad8f6caf4bdb8a416e7f6bba225323a75c55b4c5ab`。変換モデルは `3a07488cc364975eed03fe01c1806a6ff2737e99f5879f70f21dc023d64a6069`。

## 高速化候補の実験

いずれも旧main MPCを使用し、同一の評価モデル、CPU、TTサイズ、1スレッドで前後を交互に5周した。各実行のスコアは一致した。時間は各周の局面合計の中央値。これらの実験は集合ごとに別の測定であり、中央値を足して全体の中央値として扱わない。

| 試行 | 局面 | 変更前 | 変更後 |
|---|---|---:|---:|
| MPC確認をTT付き非選択探索に変更 | FFO 40〜44 | 3.548秒 | 3.488秒 |
| 同上 | FFO 45〜47 | 7.143秒 | 7.514秒 |
| 同上 | FFO 48〜49 | 13.159秒 | 12.740秒 |
| 局所終盤探索の確定石判定を省略 | FFO 40〜44 | 3.526秒 | 3.494秒 |
| 局所TTを各層2048から4096項目に拡大 | FFO 40〜44 | 3.651秒 | 3.705秒 |

確認探索の変更はFFO 49のノードを約284Mから218Mへ減らしたが、45・46・48では増えた。40〜44および48〜49は改善した一方、45〜47が約5.2%悪化したため採用していない。確定石判定の省略は差が小さく測定変動と重なるため採用していない。局所TTの拡大も改善を確認できず採用していない。`deft-tt-probe*.tsv/json`、`deft-no-stability.*`、`deft-4096.*` が生データ。

FFO 43の1ms間隔ユーザー空間サンプリングでは、局所終盤探索 `endgame_score_entered` 34.1%、`tail_score_impl` 19.9%、`null_window_upper` 10.7%。これらは実行ファイル内のシンボルに対応できたサンプルの比率で、ハードウェアカウンタでも処理時間の厳密な内訳でもない。`deft-main-ffo43-profile.json` と `.samples` を保存した。
