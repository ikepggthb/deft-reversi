# 旧アプリケーションの扱い

CLI・Webのディレクトリは元の場所に保存している。ルートのCargoワークスペースには含めない。学習用の空のクレート `deft-reversi-learn` は削除し、新しい学習器 [deft-reversi-train](../deft-reversi-train/README.md) に置き換えた。

CLI・Webのエンジンへのpath依存は新エンジンの場所を指すが、呼び出しているAPIは旧版のままである。単独ビルドもAPI移植が必要であり、動作するアプリケーションとしては提供していない。旧エンジンのソースはGit履歴から参照できる。

移植時は新エンジンのREADMEを参照し、モデル読込・Engineの所有・探索要求と停止・結果の扱いを更新する。Web/WASMはネイティブのスレッド実装を含むため別途対応を要する。

過去のWebビルド手順を含む `build_note.md` は旧版の参考記録である。
