# 旧アプリケーションの扱い

Web・学習用のディレクトリは元の場所に保存している。ルートのCargoワークスペースには含めない。CLI は新APIに移植し、ワークスペースに戻した（[deft-reversi-cli](../deft-reversi-cli/README.md)）。

Webのエンジンへのpath依存は新エンジンの場所を指すが、呼び出しているAPIは旧版のままである。単独ビルドもAPI移植が必要であり、動作するアプリケーションとしては提供していない。旧エンジンのソースはGit履歴から参照できる。

移植時は新エンジンのREADMEを参照し、モデル読込・Engineの所有・探索要求と停止・結果の扱いを更新する。Web/WASMはネイティブのスレッド実装を含むため別途対応を要する。学習用スクリプトとデータは保存しているが今回の検証対象外。

過去のWebビルド手順を含む `build_note.md` は旧版の参考記録である。
