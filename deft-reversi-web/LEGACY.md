# 移植前のアプリケーション

このディレクトリはワークスペースの検証対象外です。旧エンジンは削除済みで、新APIへの移植は未実施です。

Webのディレクトリは元の場所に保存し、ルートのCargoワークスペースには含めない。CLI は新APIに移植し、ワークスペースに戻した（[deft-reversi-cli](../deft-reversi-cli/README.md)）。学習用の空のクレート `deft-reversi-learn` は削除し、新しい学習器 [deft-reversi-train](../deft-reversi-train/README.md) に置き換えた。

Webのエンジンへのpath依存は新エンジンの場所を指すが、呼び出しているAPIは旧版のままである。単独ビルドもAPI移植が必要であり、動作するアプリケーションとしては提供していない。旧エンジンのソースはGit履歴から参照できる。

移植時は新エンジンのREADMEを参照し、モデル読込・Engineの所有・探索要求と停止・結果の扱いを更新する。Web/WASMはネイティブのスレッド実装を含むため別途対応を要する。

過去のWebビルド手順を含むリポジトリ直下の `build_note.md` は旧版の参考記録である。
