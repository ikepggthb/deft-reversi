# Deft Reversi Book ガイド

`deft_reversi_book` は、リバーシの Book データベースを作成・育成し、対局で利用するためのクレートである。局面ごとの評価値と最良の未登録手を中心にデータを持ち、詳細な探索記録は共有して保存する。

Book を扱うファイルには次の 2 種類がある。

- **`.dbook-work`（作業用ワークスペース）**: Book の生成・更新・再開に必要なデータをすべて保存するファイル。
- **`.dbook`（対局用スナップショット）**: 対局時に高速に読み取るためのコンパクトな読み取り専用ファイル。生成や再開には使わない。

## 基本の流れ

1. 校正済みの評価モデルを用意し、小さい予算から `.dbook-work` を生成する（`build`）。
2. 探索範囲（`--max-plies`）や損失条件（`--loss` 等）を調整して有望な分岐を伸ばし（`extend`）、必要に応じてレベルを上げる。子局面を育てた結果は自動で親局面へ反映される。
3. 未登録のまま残っている候補手を調べ直したいときは `leaves` を使い、局面の品質や採用元を確認したいときは `inspect` を使う。
4. 対局で使うときは `.dbook-work` から `.dbook` を書き出す（`export`）。対局中に勝手に Book を生成・保存はしない。

対局時の利用条件（`UsePolicy`）の既定値は、中盤が深さ 12・選択率 95% 以上、選択的終盤が選択率 85% 以上である。これは API の既定値であり、棋力を最適化した推奨値ではない。Book に使える手がない場合は通常探索へ戻す。完全読み切り・選択的終盤・中盤推定は区別して扱い、生成の速さや参照の速さだけで強い Book ができたとは判断しない。
